## ภาพรวม

เกมนี้คือนิยายแฟนตาซีที่ผู้เล่นเขียนเองผ่านการเลือก เริ่มตั้งแต่วันเกิดจนวันตาย แล้วได้ "ชีวประวัติ" หนึ่งเล่มติดมือกลับไป เราใช้โครงแบบ [Way of Xian](https://way-of-xian.wox-game.workers.dev/) แต่เปลี่ยนโลกเป็นแฟนตาซีสาย DnD และเพิ่มสิ่งที่ต้นแบบยังไม่มี คือของสวมใส่ที่โชว์บนตัวละครจริง กับการทอยเต๋าแบบ DnD

เล่นบนเว็บ ไม่ต้องติดตั้ง ออกแบบให้มือถือแนวตั้งเป็นหลัก แล้วรองรับแนวนอนและเดสก์ท็อปด้วย ชื่อเกมยังไม่ตั้ง thread เนื้อเรื่องจะเสนอ 5 ชื่อหลังวางโลกเสร็จ

## Core loop และโครงเรื่อง

เล่นหนึ่งรอบคือหนึ่งชีวิต ตั้งเป้าไว้ที่ 30 ถึง 60 นาทีต่อชีวิต ตายแล้วได้อ่านชีวประวัติ ได้ปลดล็อกของใหม่ แล้วอยากเกิดใหม่เพื่อลองทางที่ไม่ได้เลือก

> ไดอะแกรม: core loop · 7 ขั้น 1 จุดตัดสิน (ดูภาพได้ใน [Claude Doc](https://claude.ai/artifact/PdEsXEtkDj9ShKBVeFQJZA))

รอบบนวนทุกเหตุการณ์จนตัวละครตาย รอบล่างเกิดครั้งเดียวต่อชีวิต และพาสิ่งที่ปลดล็อกไปให้ชีวิตถัดไป

### ช่วงชีวิต

| ช่วง | อายุ (มนุษย์) | สิ่งที่เกิดขึ้น |
| --- | --- | --- |
| ทารก | 0–2 | ลางกำเนิด ครอบครัว พิธีเล็กๆ ที่บอกนิสัย |
| วัยเด็ก | 3–11 | เพื่อน ครู ความกลัว พรสวรรค์เริ่มโผล่ stat โตเร็ว |
| วัยรุ่น | 12–17 | ฝึกวิชา และ "พิธีเลือกทาง" ที่กำหนด class |
| ผู้ใหญ่ | 18–40 | ผจญภัย กิลด์ สงคราม ความรัก เป็นช่วงที่ได้ของมากที่สุด |
| วัยกลางคน | 41–60 | ตำแหน่ง ครอบครัว ศัตรูเก่ากลับมาทวงหนี้ |
| ชรา | 61 ขึ้นไป | ลูกศิษย์ มรดก ความตาย |

เผ่าที่อายุยืนกว่ามนุษย์จะยืดความยาวของแต่ละช่วง แต่จำนวนเหตุการณ์ต่อช่วงเท่าเดิม เอลฟ์อายุ 700 ปีจึงไม่ต้องใช้เนื้อเรื่องมากกว่ามนุษย์ 10 เท่า

### เหตุการณ์มี 4 แบบ

1. **หมุดชีวิต** เกิดทุกชีวิต เช่น กำเนิด พิธีเลือกทาง ความตาย
2. **เหตุการณ์สุ่ม (storylet)** มีเงื่อนไข เช่น อายุ สถานที่ stat ของที่มี และสิ่งที่เคยทำ ระบบสุ่มจากกองที่เข้าเงื่อนไขตามน้ำหนัก
3. **สายเรื่อง (arc)** เหตุการณ์หลายตอนที่ต่อกันข้ามปี เช่น ดาบต้องคำสาปที่ตามตัวไป 20 ปี
4. **ผลสะท้อนกลับ (callback)** สิ่งที่เลือกไว้นานแล้วกลับมาหา เช่น เด็กที่เคยช่วยไว้กลายเป็นหัวหน้าโจร แบบนี้คือสิ่งที่ทำให้อ่านแล้วเหมือนนิยาย

ปีหนึ่งมี 1 ถึง 3 เหตุการณ์ ระหว่างนั้นมีบรรทัดชีวิตประจำวันที่ไม่ต้องเลือก เหมือนต้นแบบ ทุกชีวิตใช้ seed สุ่มค่าเดียว เล่นซ้ำและหาบั๊กได้

### ตัวเลือกมี 4 แบบ

- **ธรรมดา** ผลแน่นอน ไม่ต้องทอย
- **ทอยเต๋า** บอก stat ค่าความยาก และโอกาสเป็น % ก่อนกด
- **ถูกล็อก** โชว์เป็นสีเทาพร้อมเหตุผล เช่น "ต้องเสน่ห์ 14" ให้ผู้เล่นรู้ว่าชีวิตหน้าควรลองอะไร
- **ปลดด้วยของหรือทักษะ** โผล่เฉพาะตอนสวมของที่มี passive นั้น หรือมี trait นั้น

### จบชีวิต

ตายแล้วได้หน้า "ชีวประวัติ" เล่าเหตุการณ์เด่นเป็นร้อยแก้ว พร้อมฉายา สถิติ และรูปตัวละครในชุดสุดท้าย กดแชร์เป็นรูปการ์ดได้ ความสำเร็จในชีวิตนั้นปลดล็อกชาติกำเนิด trait และของตกทอด 1 ชิ้นสำหรับชีวิตถัดไป

การต่อสู้ในรุ่นแรกเป็นการทอยเช็ค 1 ถึง 3 รอบพร้อมร้อยแก้วบรรยาย ไม่มีหน้าจอต่อสู้แบบเทิร์น เพื่อให้เกมยังเป็นนิยายอยู่

## ระบบ Stat

ใช้ 6 ค่าหลักแบบ DnD ช่วง 1 ถึง 20 (ของวิเศษดันเกินได้ถึง 30) เช็คด้วย d20 บวกโบนัส เทียบค่าความยาก (DC) และผู้เล่นเห็นโอกาสเป็น % ก่อนกดเสมอ ชื่อภาษาไทยด้านล่างเป็นร่าง ให้ thread เนื้อเรื่องเกลาอีกที

| ค่า | ชื่อไทย (ร่าง) | ใช้ทำอะไร | โตจาก |
| --- | --- | --- | --- |
| STR | พลัง | ต่อสู้ประชิด ยก ปีน ข่มด้วยกำลัง | งานหนัก ฝึกอาวุธ |
| DEX | ว่องไว | ลอบเร้น ล้วง ยิงธนู หลบ | เล่นซน ล่าสัตว์ งานฝีมือ |
| CON | อึด | HP อายุขัย ทนพิษและโรค | กินดี งานกลางแจ้ง รอดจากไข้ |
| INT | ปัญญา | เวทอาร์เคน ความรู้ สืบสวน | อ่านหนังสือ ครู หอสมุด |
| WIS | ญาณ | สังเกต เอาตัวรอด เวทนักบวชและดรูอิด | ธรรมชาติ ศาสนา ความผิดพลาด |
| CHA | เสน่ห์ | เจรจา หลอก แสดง นำคน | สังคม การแสดง ความรัก |

### การเช็ค

ผล = d20 + โบนัส stat + โบนัสความชำนาญ (ถ้ามี) + โบนัสจากของ ต้องได้ไม่น้อยกว่า DC โบนัส stat คิดแบบ DnD คือ (ค่า − 10) ÷ 2 ปัดลง เช่น 14 ได้ +2

- **DC:** 5 ง่าย · 10 ปกติ · 15 ยาก · 20 ยากมาก · 25 แทบเป็นไปไม่ได้
- **ได้เปรียบ / เสียเปรียบ:** ทอยสองลูก เอาสูงหรือต่ำ มาจาก trait ของ หรือสถานการณ์
- **ทอยได้ 20 / ทอยได้ 1:** มีผลพิเศษและร้อยแก้วเฉพาะ
- **แรงบันดาลใจ:** ได้เมื่อเลือกตามนิสัยตัวละคร ใช้ทอยใหม่ได้ 1 ครั้ง
- ปุ่มตัวเลือกโชว์แบบ "ว่องไว DC 12 · 65%" กดแล้วเห็นเต๋าหมุนสั้นๆ ไม่เกิน 1 วินาที

### ค่าเริ่มต้นและการเติบโต

- **เกิด:** ฐาน 8 ทุกค่า บวกโบนัสเผ่าและชาติกำเนิด โหมดสร้างเองใช้แต้มซื้อ 27 แต้มแบบ DnD โหมดสุ่มทอย 4d6 ตัดลูกต่ำสุด
- **วัยเด็กถึงวัยรุ่น:** เหตุการณ์ให้ +1 หรือ −1 บ่อย ตัวละครจะออกมาต่างกันจริงตามที่เลือก
- **ผู้ใหญ่:** โตช้าลง ได้ XP จากการผจญภัย เลเวล 1 ถึง 20 ได้เพิ่ม stat ที่เลเวล 4, 8, 12, 16, 19
- **ชรา:** พลัง ว่องไว อึด ค่อยๆ ลด ญาณค่อยๆ เพิ่ม

### Class และทักษะ

Class ไม่ได้เลือกจากเมนู ทุกตัวเลือกตั้งแต่เด็กสะสมแต้มความโน้มเอียง พอถึงพิธีเลือกทางระบบเสนอ 2 ถึง 3 ทางที่เข้ากับชีวิตที่ผ่านมา รวมทาง "ไม่เป็นนักผจญภัย" ที่ใช้ชีวิตเป็นชาวบ้าน พ่อค้า หรือขุนนางก็ได้ SRD มี 12 class รุ่นแรกเปิด 6 class: นักรบ โจร นักเวท นักบวช เรนเจอร์ บาร์ด

ทักษะใช้ชุดของ SRD เช่น ลอบเร้น สังเกต อาร์เคน เจรจา ได้ความชำนาญจาก class พื้นเพ และการฝึกในเหตุการณ์ นอกจากค่าตัวเลข ทุกอย่างที่เคยทำเก็บเป็น flag เช่น "รู้ภาษาเอลฟ์" หรือ "ติดหนี้กิลด์โจร" ให้เหตุการณ์หลังจากนั้นเรียกใช้

| แหวน × 2 | ไม่ | แหวนป้องกัน แหวนตราตระกูล |
| สร้อย / เครื่องราง | ไม่ | สัญลักษณ์ศักดิ์สิทธิ์ เครื่องรางกันพิษ |

มีแท็บ "ชุดแต่งกาย" แบบต้นแบบด้วย ใส่ของชิ้นหนึ่งเพื่อเอา stat แต่ให้ตัวละครดูเหมือนสวมอีกชิ้น ระบบ sprite ซ้อนชั้นทำให้ได้ฟีเจอร์นี้ฟรี

### ระดับของ

| ระดับ | จำนวน stat | Passive |
| --- | --- | --- |
| ธรรมดา (Common) | 0–1 | ไม่มี |
| ดี (Uncommon) | 1–2 | ไม่มี |
| หายาก (Rare) | 2–3 | สุ่ม 1 อย่างจากคลัง passive ทั่วไป |
| หายากมาก (Very rare) | 3 | passive ทั่วไป 1 อย่าง แรงขึ้น อาจมีเงื่อนไข |
| ตำนาน (Legendary) | 3–4 | passive เฉพาะตัว เขียนมือ มีชื่อและประวัติ |
| อาร์ติแฟกต์ (Artifact) | พิเศษ | passive เฉพาะตัว พร้อมสายเรื่องของมันเอง มีชิ้นเดียวในโลก |

ของหนึ่งชิ้น = รูปทรงฐาน (ดาบยาว) + วัสดุ (เหล็ก เงิน มิธริล) + ระดับ + stat + passive วัสดุคือการสลับสีของ sprite ตัวเดิม ดาบที่วาดครั้งเดียวจึงกลายเป็น 6 ถึง 8 เล่มที่หน้าตาต่างกัน

### Passive มี 5 แบบ

1. **ค่าคงที่** เช่น AC +1 หรือ พลัง +2
2. **ปรับการทอย** เช่น ได้เปรียบตอนลอบเร้นในที่มืด หรือทอยได้ 1 ให้ทอยใหม่
3. **ทริกเกอร์** เช่น HP ต่ำกว่า 25% ครั้งแรกในชีวิต รอดตายแทน
4. **ปลดตัวเลือก** เช่น เหตุการณ์ที่มีแท็ก "ภูตผี" มีตัวเลือกเพิ่มที่คนอื่นไม่เห็น
5. **ของมีเรื่องเล่า** ดาบมีวิญญาณพูดแทรกในบันทึก หรือของต้องสาปที่ถอดไม่ได้จนกว่าจะจบสายเรื่องของมัน

แบบ 4 และ 5 คือจุดต่างจากเกม RPG ทั่วไป ของในเกมนี้เปลี่ยนเนื้อเรื่องได้ ไม่ใช่แค่ตัวเลข

### ตัวอย่างข้อมูลของ 1 ชิ้น

```yaml
id: sword_whisper            # ชื่อและเนื้อเรื่องเป็นตัวอย่าง
base: longsword
material: blackened_steel     # = palette ของ sprite
rarity: legendary
attune: true
stats: { STR: 1, attack: 2 }
passive:
  id: whisper
  effects:
    - check_mod: { skill: deception, advantage: true }
    - unlock_choice: { event_tag: undead, choice: speak_through_blade }
sprite: { slot: main_hand, shape: longsword, palette: blackened_steel, glow: legendary }
```

ได้ของจาก รางวัลเหตุการณ์ ร้านในเมือง ของที่เก็บได้ระหว่างผจญภัย ของขวัญจาก NPC และมรดกจากชีวิตก่อน เป้ารุ่นแรกประมาณ 60 ชิ้น: 40 ชิ้นธรรมดาถึงดี 15 ชิ้นหายาก และ 5 ชิ้นตำนานที่ thread เนื้อเรื่องเขียนประวัติ

## ระบบ sprite ซ้อนชั้น: วาดครั้งเดียว ใช้ซ้ำ

ตัวละครทุกตัวใช้ร่างฐานท่าเดียว ขนาดเดียว แล้วซ้อนชิ้นส่วนเป็นชั้นบนกริดพิกเซลเดียวกัน ชิ้นส่วนวาดครั้งเดียว แล้วเกมเปลี่ยนสีด้วย palette ตอนเล่น ใส่ของใหม่จึงไม่ต้องวาดตัวละครใหม่ทั้งตัว และ NPC ทุกคนในเกมก็สุ่มประกอบจากชิ้นชุดเดียวกันได้

> ไดอะแกรม: sprite ซ้อนชั้น · 14 ชั้น 4 ขั้นตอน (ดูภาพได้ใน [Claude Doc](https://claude.ai/artifact/PdEsXEtkDj9ShKBVeFQJZA))

ชั้นสีฟ้า 7 ชั้นคือของสวมใส่ที่เปลี่ยนได้ ใส่ของใหม่คือการสลับชิ้นในชั้นเดียว ชั้นอื่นไม่ต้องแตะ

### หลัก 5 ข้อ

1. **ร่างฐานเดียว ท่าเดียว** ทุกชั้นวาดบน canvas ขนาดเท่ากัน (64×96 px) ตำแหน่งตรงกันทุกพิกเซล จึงไม่ต้องตั้งตำแหน่งทีละชิ้น
2. **ลำดับชั้นตายตัว** จากหลังไปหน้า ตามภาพด้านบน ผมและผ้าคลุมแยกเป็นชิ้นหน้าและชิ้นหลัง เพื่อให้ไหล่กับเกราะอยู่ระหว่างกลางได้
3. **สีมาจาก palette ไม่ใช่จากการวาด** วาดด้วยสีกุญแจไม่กี่สี เช่น ผิว 3 ระดับ วัสดุหลัก 3 ระดับ วัสดุรอง 2 ระดับ เกมแทนสีกุญแจด้วยสีจริงตอนโหลด สีผิว สีผม สีตา วัสดุของ และผมหงอกตอนแก่ มาจากการวาดชุดเดียว
4. **ชิ้นที่ทับกันใช้ flag** เช่น หมวกเหล็กมี `hides: [hair_front]` เกมซ่อนหน้าม้าให้ ไม่ต้องวาดผมทุกทรงเพิ่มอีกแบบ
5. **ประกอบครั้งเดียว เก็บไว้ใช้ทุกที่** เกมรวมชั้นเป็นภาพเดียวเฉพาะตอนเปลี่ยนของ รูปหน้าในกล่องเหตุการณ์ ช่องเซฟ และการ์ดชีวประวัติ คือการครอปครึ่งบนจากภาพเต็มตัว ไม่ต้องวาด portrait แยก

### วาดน้อย ได้เยอะ

ตัวเลขด้านล่างเป็นประมาณการสำหรับรุ่นแรก คิดที่วัสดุ 6 สีต่อของหนึ่งทรง รวมวาดราว 80 ชิ้น ได้ของที่หน้าตาต่างกันกว่า 250 แบบ

### วิธีวาดและส่งเข้าเกม

ผมแนะนำให้ thread ศิลป์วาดทุกชิ้นเป็นตารางพิกเซลแบบข้อความ หนึ่งตัวอักษรต่อหนึ่งพิกเซล เก็บใน repo แล้วให้ script แปลงเป็น PNG atlas วิธีนี้ Claude วาดเองได้แม่น ตรวจทีละพิกเซลใน git ได้ และสลับสีได้ทันที ถ้าวันหน้ามีคนวาดมือใน Aseprite ก็นำเข้าได้ โดยตั้งชื่อ layer ตามช่อง

## Art direction

ยึดสไตล์จากรูปที่ Phupha แนบมา แล้วขยายจากภาพครึ่งตัวเป็นเต็มตัว โดยคงขนาดหัวเท่าภาพเดิมและต่อลำตัวลงมา ทางเลือกทั้งหมดอยู่ในตารางคำถาม Art ท้ายเอกสาร Phupha ตกลงตามที่แนะนำเมื่อ 7 พ.ย. 2026

### สิ่งที่เห็นในรูปต้นแบบ

- เส้นขอบ 1 px สีเข้มเกือบดำรอบตัว เส้นในใช้เฉดเข้มของสีนั้น
- เงาแบบเรียบ 2 ถึง 3 ระดับต่อสี แทบไม่มี dithering
- หัวใหญ่ ตาโตมีจุดสะท้อนแสงสีขาว จมูกแทบไม่มี ปากเส้นเดียว สีหน้าแก้มเป็นจุด
- สีสดแต่ไม่ฉูดฉาด พื้นหลังการ์ดเป็นขาวหรือพาสเทล
- มีไอคอนหมวดหมู่อยู่มุมซ้ายบนของการ์ด ใช้ต่อได้กับการ์ดชาติกำเนิดและพรสวรรค์

### งานศิลป์ที่ต้องมี

- **ตัวละคร:** ทั้งหมดใช้ระบบซ้อนชั้นด้านบน รวมถึง NPC
- **ไอคอนของ:** ครอปจากชั้นของชิ้นนั้นอัตโนมัติ ไม่ต้องวาดไอคอนแยก
- **มอนสเตอร์:** ตัวที่รูปร่างคล้ายคนใช้ร่างฐานได้ ตัวอื่นวาดเดี่ยว รุ่นแรกราว 10 ตัว
- **ฉาก:** แถบฉากแนวนอนแบบต้นแบบ ซ้อน parallax 2 ถึง 3 ชั้น รุ่นแรกราว 6 ฉาก รายชื่อสถานที่รอ Lore กลางวันกลางคืนใช้ palette แทนการวาดใหม่
- **UI:** กรอบ ปุ่ม และไอคอน stat ขนาด 16 หรือ 24 px

### ขั้นแรกของ thread ศิลป์

ทำภาพตั้งต้น 3 ภาพให้ Phupha อนุมัติก่อนผลิตจริง: ร่างฐานเปล่า, นักรบเกราะเหล็ก, นักเวทในชุดคลุม ทั้งสามภาพต้องประกอบจากชั้นจริง เพื่อพิสูจน์ว่าระบบซ้อนชั้นใช้ได้ตั้งแต่วันแรก

Thread ศิลป์เปิดเว็บหา reference ได้ เช่น ทรงเกราะยุคกลาง หรือเทคนิควาด pixel แต่ใช้เพื่อศึกษาเท่านั้น ห้ามลอก sprite ของเกมอื่นมาใช้

## UX/UI: มือถือแนวตั้ง แนวนอน และเดสก์ท็อป

ออกแบบมือถือแนวตั้งก่อน เพราะเป็นท่าที่คนอ่านนิยายบนมือถือ แล้วให้หน้าจอเดิมจัดตัวใหม่เป็น 2 คอลัมน์ตอนแนวนอน และ 3 คอลัมน์บนเดสก์ท็อป ใช้ component ชุดเดียว เปลี่ยนแค่การจัดวาง

> ไดอะแกรม: wireframe · 3 ขนาดจอ (ดูภาพได้ใน [Claude Doc](https://claude.ai/artifact/PdEsXEtkDj9ShKBVeFQJZA))

ตัวเลือกอยู่ล่างเสมอในทุกจอ เพราะเป็นจุดที่ผู้เล่นกดบ่อยที่สุด ส่วนตัวละครเต็มตัวก็มีที่ให้เห็นของที่สวมใส่ทุกขนาดจอ

| หน้าจอ | เงื่อนไข | การจัดวาง |
| --- | --- | --- |
| มือถือแนวตั้ง | กว้างน้อยกว่า 600 px และสูงกว่ากว้าง | แถบบนบาง, ฉากกับตัวละครสูงราว 25% ของจอ, แถว stat, พื้นที่อ่าน, ตัวเลือกเป็นแผ่นเลื่อนขึ้นจากล่าง, เมนูล่าง 5 ปุ่ม |
| มือถือแนวนอน | สูงน้อยกว่า 500 px | เมนูเป็นแถบไอคอนซ้าย ไม่มีแถบบน, ซ้าย 40% ตัวละครเต็มตัวบนพื้นฉากกับ stat, ขวา 60% เรื่องและตัวเลือก |
| แท็บเล็ตและเดสก์ท็อป | กว้างตั้งแต่ 1024 px | ฉากเต็มความกว้างด้านบน, ซ้ายตัวละคร stat ของสวมใส่, กลางเรื่องกว้างไม่เกิน 680 px, ขวาแท็บผู้คน แผนที่ ภารกิจ |

เมนูล่างบนมือถือมี 5 ปุ่ม: เรื่องราว · ตัวละคร (stat ของสวมใส่ กระเป๋า) · ผู้คน · โลก (แผนที่ ข่าว กลุ่มอำนาจ) · เพิ่มเติม (เซฟ ตั้งค่า ชีวประวัติ)

### การอ่านและการเลือก

- ข้อความขึ้นทีละย่อหน้า แตะเพื่ออ่านต่อ หรือเปิดเล่นอัตโนมัติ 1x ถึง 5x และหยุดได้
- ปุ่มตัวเลือกสูงอย่างน้อย 48 px อยู่ในระยะนิ้วโป้ง บอกค่าเช็คและ % ตัวเลือกที่ล็อกบอกเหตุผล
- พักการตัดสินใจไว้ก่อนได้แบบต้นแบบ แต่เวลาในเกมหยุดระหว่างรอ
- ค่าที่เปลี่ยนขึ้นสีในบรรทัด และเด้งเบาๆ ที่แถว stat
- ดูรายละเอียดของ: แตะค้างบนมือถือ ชี้เมาส์บนเดสก์ท็อป
- เดสก์ท็อปมีปุ่มลัด: เลข 1–5 เลือก, Space อ่านต่อ, P หยุด

### ภาษาไทยบนจอ

- ระยะบรรทัด 1.7 ถึง 1.8 เท่า เพราะสระบน สระล่าง และวรรณยุกต์ซ้อนกันได้หลายชั้น
- ตัวอักษรเนื้อเรื่อง 17 ถึง 18 px บนมือถือ ปรับขนาดได้ในตั้งค่า
- เอฟเฟกต์พิมพ์ทีละตัวต้องตัดตามกลุ่มอักษรด้วย `Intl.Segmenter` ไม่งั้นสระกับวรรณยุกต์จะโผล่ก่อนพยัญชนะ
- ทดสอบการตัดคำท้ายบรรทัดบน Safari, Chrome และ Firefox ถ้าตัดผิดค่อยใช้ `Intl.Segmenter` แทรกจุดตัดตอน build
- ฟอนต์: หัวข้อ Noto Serif Thai เนื้อหา Anuphan ตัวเลข stat ใช้ฟอนต์ pixel

### เทคนิคมือถือ

- ใช้ `100dvh` และ `env(safe-area-inset-*)` กันแถบเบราว์เซอร์และรอยบากทับปุ่ม
- หมุนจอแล้วตำแหน่งที่อ่านค้างต้องไม่หาย
- เป็น PWA: ติดตั้งลงหน้าจอได้ เล่นออฟไลน์ได้ เต็มจอได้
- สั่นเบาๆ ตอนทอยเต๋าบน Android (iOS Safari ไม่รองรับ)
- ตั้งค่ามี ขนาดตัวอักษร ความเร็วข้อความ ลดแอนิเมชัน และโหมดสว่างหรือมืด

## Tech stack และข้อมูลเนื้อเรื่อง

รุ่นแรกเป็นเว็บ static ไม่มีเซิร์ฟเวอร์: Vite + TypeScript + Preact วาดตัวละครด้วย Canvas 2D เนื้อเรื่องเป็นไฟล์ YAML ใน repo เซฟลงเครื่องผู้เล่น และ deploy บน Cloudflare Pages ไม่ใช้ game engine เพราะเกมนี้คือข้อความ ปุ่ม และ sprite ไม่กี่ตัว engine จะเพิ่มขนาดโหลดและทำ UI ภาษาไทยยากกว่า HTML

| ส่วน | เลือก | เหตุผล |
| --- | --- | --- |
| ภาษาและ build | TypeScript + Vite | เร็ว type ช่วยจับเนื้อเรื่องที่อ้างผิด |
| UI | Preact + Signals | API แบบ React แต่เบามาก โหลดไวบนมือถือ |
| ตัวละครและฉาก | Canvas 2D | พอสำหรับ sprite ไม่กี่สิบชิ้น |
| เนื้อเรื่อง | YAML แปลงเป็น JSON ตอน build ตรวจด้วย Zod | คนเขียนอ่านง่าย ดู diff ง่าย จับข้อผิดก่อนขึ้นเว็บ |
| การสุ่ม | seed เดียวต่อชีวิต | เล่นซ้ำ ทดสอบ และแชร์ชีวิตได้ |
| เซฟ | IndexedDB 3 ช่อง เซฟอัตโนมัติทุกเหตุการณ์ ส่งออกเป็นรหัสได้ | ไม่ต้องมีบัญชี ย้ายเครื่องได้ |
| ทดสอบ | Vitest, ตัวตรวจเนื้อเรื่อง, Playwright ถ่ายจอ 3 ขนาด | กันเนื้อเรื่องพังและ layout เพี้ยน |
| Deploy | Cloudflare Pages มีลิงก์ทดลองทุก PR | ฟรี เปิดเร็วในไทย |

ตัวตรวจเนื้อเรื่องจะหา เหตุการณ์ที่ไม่มีทางเกิด, flag ที่ถูกอ่านแต่ไม่เคยถูกตั้ง, ของที่อ้างถึงแต่ไม่มีจริง และตัวเลือกที่ไม่มีผลอะไร

### คู่มือเขียนภาษาไทยสำหรับ thread เนื้อเรื่อง

เป้าคือให้คนอ่านรู้สึกว่ากำลังอ่านนิยายแฟนตาซีไทยที่คนเขียน ไม่ใช่ข้อความแปลหรือข้อความที่ AI สร้าง

**ทำ**

- เล่าด้วยรายละเอียดที่จับต้องได้ กลิ่น เสียง สิ่งของ แทนคำคุณศัพท์ลอยๆ
- ประโยคสั้นยาวสลับกัน ฉากตึงใช้ประโยคสั้น
- ตัวละครแต่ละคนพูดไม่เหมือนกัน ตามชนชั้น ถิ่น และอาชีพ
- ปล่อยให้ผู้อ่านสรุปเอง ไม่อธิบายอารมณ์ที่ฉากแสดงไปแล้ว
- ใช้สำนวนไทยเมื่อเข้าที่ ไม่ยัดทุกย่อหน้า

**เลี่ยง**

- โครง "ไม่ใช่แค่... แต่ยัง..." และการไล่คำคุณศัพท์สามคำติดกัน
- "ราวกับว่า" "ท่ามกลาง" "เต็มไปด้วย" ที่โผล่ซ้ำๆ
- จบย่อหน้าด้วยข้อคิดหรือสรุปบทเรียน
- ภาษาแปล: "ถูก" ทุกประโยค, "ทำการ", "ได้รับการ", "ซึ่ง" ต่อกันยาว, "มัน" นำประโยคแทนสิ่งของ
- คำอังกฤษทับศัพท์ในเนื้อเรื่อง ยกเว้นชื่อเฉพาะ

**ขั้นตอน:** เขียน ตรวจกับรายการเลี่ยง แล้วอ่านออกเสียงในใจ ก่อนเขียนจำนวนมากให้ส่งฉากตั้งต้น 3 ฉาก (กำเนิด ต่อสู้ ความตาย) ให้ Phupha อนุมัติเป็นมาตรฐานสำนวน
