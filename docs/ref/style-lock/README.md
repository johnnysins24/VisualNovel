# แบบที่ล็อกไว้

Phupha ล็อกแบบนี้เมื่อ 7 พ.ย. 2026: sprite ทุกตัวของเถ้ากับดาวต้องออกมาหน้าตา ลายเส้น และสีแบบภาพในโฟลเดอร์นี้ ภาพชุดนี้ทำจากโค้ดตัวละครของ Voxel Realm แต่ใช้เป็นแบบให้ดูเท่านั้น เกมสร้างภาพด้วยเครื่องมือ 2D ของตัวเอง ไม่ใช้โค้ดหรือไฟล์จาก Voxel Realm

ภาพทุกไฟล์ขยาย 4 เท่า พื้นสีมุก (#f2f2f9) ไม่ใช่ส่วนของ sprite

| ไฟล์ | ภาพ |
| --- | --- |
| `bare.png` | ตัวเปล่าชายหญิงบน canvas 64×96 ขนาดจริง |
| `classes.png` | ชุดเริ่มต้น 6 class เรียงตามนี้: นักรบ นักเวท พราน นักบวช นักย่อง กวีเร่ แถวบนชาย แถวล่างหญิง |
| `steps_warrior.png` `steps_sorcerer.png` | ใส่ชุดทีละชิ้นจากตัวเปล่าถึงครบชุด |
| `expressions_f.png` `expressions_m.png` | 17 อารมณ์: ปกติ ยิ้ม ดีใจ หัวเราะ เศร้า ร้องไห้ โกรธ ตกใจ เขิน ยิ้มเยาะ เจ็บ ง่วง หลับ ขยิบตา สลบ กิน จดจ่อ |

## ค่าที่วัดจากภาพชุดนี้

| ด้าน | ค่าที่ล็อก |
| --- | --- |
| สัดส่วน | สูง 3.25 หัว ชาย 51 px หญิง 48 px ไม่นับขอบ หัวรวมผมกว้างและสูงราว 15 px |
| เส้นขอบ | 1 px สี #2b2840 รอบเงาทั้งตัว ช่อง 1 px ระหว่างแขนกับลำตัวและระหว่างขาก็กลายเป็นเส้นขอบ |
| แสงเงา | นุ่ม กลางชิ้นสว่าง ขอบชิ้นมืดลง ไม่มีเงาตกแข็ง |
| ผิวสัมผัส | ผิวและผมเรียบ ผ้าและหนังมีจุดเม็ดละเอียด โลหะมีไฮไลต์ที่ขอบบน |
| สี | ตาเห็นราว 3 ถึง 5 ระดับต่อวัสดุ เครื่องมือของเกมใช้ 4 ถึง 5 ระดับต่อวัสดุ ให้ทั้งเกมอยู่ในราว 48 สีตามข้อ A7 |
| หน้า | ขนตาเข้มหนา 3 px ทับบนตา 2×2 px (บนเข้ม ล่างอ่อน) จมูกและปากเป็นเส้นสีเนื้อเข้มสั้น ๆ แก้มชมพู ผมหน้าม้ามีเส้นผม |
| อวัยวะ | คอโผล่ บ่าลาด แขน 3 px ข้อมือ 2 px มือ 3 px เท้า 4 px ซ้ายขวาเท่ากันทุกพิกเซล |
| การวาง | หันหน้าตรง (A5) ยืนบนแถวเดียวกันใน canvas 64×96 (A2) |
