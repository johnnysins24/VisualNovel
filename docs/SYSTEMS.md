# ระบบเกมและวิธีเขียนเหตุการณ์ (YAML)

ตัวเลขสมดุลทั้งหมดอยู่ที่ `src/engine/balance.ts` ไฟล์เดียว ตัวอย่างการใช้งานจริงดูที่ `tests/fixtures/content/` (เนื้อหาทดสอบ ไม่ใช่ lore)

## Stat และชื่อ

id ในไฟล์ YAML ใช้ `STR DEX CON INT WIS CHA` ส่วนผู้เล่นเห็น กำลัง ว่องไว อึด ปัญญา ญาณ เสน่ห์ (`STAT_TH`)

## เผ่า (ได้จาก flag)

ตั้ง flag `race_human`, `race_elf`, `race_dwarf` หรือ `race_tiefling` ใน effects ตอนเกิด ระบบจะให้โบนัส SRD ครั้งเดียว สุ่มพ่อแม่และชื่อตัวละครจากกลุ่มชื่อของเผ่า (`content/names.yaml`) และให้สิ่งติดตัว `curse_brand` (ตราร้อน) กับทีฟลิ่ง กลุ่มชื่อใน `names.yaml` (`race:` คือ id กลุ่ม จะตั้งเป็นอะไรก็ได้ เช่น `temple_foundling`) มี `male`, `female` และ `surname` (ไม่บังคับ) ถ้าเผ่านั้นยังไม่มีกลุ่มชื่อ ชื่อจะเป็น "ผู้เดินทาง" และพ่อแม่เป็น "พ่อ" "แม่"

**เปลี่ยนกลุ่มชื่อตามบ้านที่เกิด** ใส่ `name_pool` ในตัวเลือกเกิดเดียวกับ flag เผ่า (ต้องตั้งพร้อมกัน เพราะชื่อสุ่มครั้งเดียว):

```yaml
effects:
  flags: [race_tiefling]
  name_pool: { self: temple_foundling, parents: none }   # none = ไม่มีพ่อแม่ที่รู้จัก ใช้ พ่อ แม่
```

`{surname}` ดึงจาก `surname` ของกลุ่มชื่อตัวเอง (ว่างถ้าไม่มี) ตัวตรวจเนื้อเรื่องเช็คว่ากลุ่มที่อ้างมีอยู่จริง

flag อื่นที่ขึ้นต้น `origin_` ใช้ได้อิสระ

## Effects ที่เพิ่มในรอบนี้

```yaml
effects:
  class: warrior | rogue | wizard | cleric | ranger | bard   # ครั้งแรกครั้งเดียว ให้ stat และ HP ตามตาราง
  god: verus | isel | talis | ossa | ulwen | belek | astel
  world: { gods: 1, demon: -1, star: 0 }      # คะแนนโลกลับ ผู้เล่นไม่เห็น (−20..20)
  alignment: { law: 2, moral: -1 }            # + คือระเบียบ/ดี  − คืออิสระ/ชั่ว (−10..10)
  reputation: { belek_bank: -2, wardens: 1 }  # ติดข้ามชีวิต (−10..10)
```

กลุ่มสำหรับ reputation: `crown lamp_church belek_bank royal_institute distillers dwarf_council star_hall wardens dock_rats ash_cult star_listeners`

## เงื่อนไข

ใช้ได้ทั้งใน `when` ของเหตุการณ์และ `requires` ของตัวเลือก: `class`, `god`, `world: {demon: [min, max]}`, `min_reputation`, `max_reputation`

เฉพาะ `when`: `age: [จาก, ถึง]` อ่านเป็น **อายุแบบมนุษย์** ทุกเผ่าโตเท่ากันจนอายุ 40 (`EVEN_AGING_UNTIL`) หลังจากนั้นร่างกายของเอลฟ์แก่ช้ากว่า 10 เท่า คนแคระ 5 เท่า (`ageScale` ใน balance.ts) เขียนเหตุการณ์ผู้ใหญ่ครั้งเดียวใช้ได้ทุกเผ่า ผู้เล่นเห็นอายุจริง · `year: [จาก, ถึง]` (ปีในโลก = ปีเกิด + อายุ ปีเกิดสุ่ม 270 ถึง 300) รายละเอียดเรื่องเวลาอยู่ในหัวข้อ "เวลาและชีวิตยาว"

## ข้อความ

- ตัวเลือกมี `text` ได้ แสดงหลังเลือก (ตัวเลือกที่มี check จะต่อกับ text ของ success/failure)
- ข้อความแบ่งย่อหน้าตามบรรทัดว่าง
- `{name}` `{surname}` `{father}` `{mother}` และ `{ชาย|หญิง}` เช่น `{เขา|เธอ}`
- `{partner}` `{p:เขา|เธอ}` คนรัก · `{child}` `{c:เขา|เธอ}` ลูกคนโตที่ยังอยู่ · `{newborn}` ลูกคนล่าสุดที่เข้ามาในครอบครัว · `{god}` เทพที่นับถือ · `{years}` จำนวนปีของเหตุการณ์หลายปี (เป็นคำ) · `{ชื่อบท}` กับ `{ชื่อบท:เขา|เธอ}` คนที่เล่นบทนั้น (ดู "ตัวแสดง")
- ค่า YAML ที่ขึ้นต้นด้วย `{` ต้องใส่เครื่องหมายคำพูด เช่น `mark: "{newborn}เกิด"`

## แนวทางและนักบวช

คะแนน alignment แบ่งเป็น 3 ช่องต่อแกน (ถึง ±3 คือเอียง) เทียบกับช่องของเทพบนตาราง 3×3 นักบวชที่ห่างเทพเกิน 1 ช่องเสียโบนัสญาณ ระบบตั้ง flag `cleric_drift` ให้ ใช้ใน `when.flags` เพื่อเขียนเหตุการณ์ "กลับตัว เปลี่ยนเทพ หรือหันไปหาสิ่งอื่น"

## รอยจอมมาร

สิ่งติดตัว `curse_brand` (ตราร้อน เซฟเก่าใช้ชื่อ `demon_mark`) ให้โบนัสทอยเมื่อ check มี `foe: demon` (ศัตรูลังเล) หรือ `foe: star` (ศัตรูมองไม่เห็น) ค่า `foe` อื่นไม่มีผล ตอนนี้เป็นสิ่งติดตัวในทะเบียนแล้ว ผลของมันจึงขึ้นในบรรทัดทอยเหมือนสิ่งติดตัวอื่น

## ชื่อเสียงข้ามชีวิต

เก็บใน `meta` แยกจากเซฟชีวิต ชีวิตใหม่เริ่มด้วยชื่อเสียงที่จบชีวิตก่อนทิ้งไว้ ปรับ `REPUTATION_CARRY` ใน balance.ts ถ้าอยากให้เลือนลง

## ตัวตรวจเนื้อเรื่อง (`npm run validate`)

จับ flag/trait ที่อ่านแต่ไม่เคยถูกตั้ง ของที่ไม่มีจริง ตัวเลือกไม่มีผล id ซ้ำ ช่วงอายุ/ปีกลับด้าน placeholder ที่พิมพ์ผิด flag `race_*` ที่ไม่มีเผ่า และกลุ่มชื่อของเผ่าที่ไม่มี ตั้ง `CONTENT_DIR=tests/fixtures/content` เพื่อตรวจ/รันด้วยเนื้อหาทดสอบ (`npm run dev:fixture`)

## ตัวละครตายก่อนอายุ 12 ไม่ได้

ก่อนอายุ `PROTECTED_AGE` (12) HP ไม่ต่ำกว่า 1 และ `die: true` ไม่มีผล ไม่ว่าเนื้อหาเขียนอะไร คนรอบตัวตายได้ตามเรื่อง (ผ่านข้อความและ flag ตามปกติ)

## เหตุการณ์ที่ต้องเกิด (`must: true`)

เหตุการณ์ปกติถูกสุ่มตามน้ำหนัก จึงอาจไม่ออกเลยตลอดช่วงอายุของมัน เรื่องที่ชีวิตต้องเจอให้ใส่ `must: true` (พิธีโตเป็นผู้ใหญ่ การเลือกอาชีพ หมายเกณฑ์ทหาร หมุดโลก ฉากปิดอายุสี่สิบ)

- ออกทันทีที่เข้าเงื่อนไข ก่อนเรื่องที่สุ่มทุกเรื่อง และไม่ใช้ตัวสุ่ม ชีวิตที่ seed เดียวกันจึงยังเดินเหมือนเดิมหลังจากนั้น
- ถ้าเข้าเงื่อนไขพร้อมกันหลายเรื่อง เรื่องที่เหลือโอกาสน้อยที่สุดออกก่อน (นับจาก `when.age` และ `when.year` เป็นจำนวนเหตุการณ์ที่เหลือ) เท่ากันให้ `weight` สูงกว่าออกก่อน
- ใช้กับ `once: false` ไม่ได้ และต้องมีเงื่อนไขอายุ ปี flag หรือ trait อย่างน้อยหนึ่งอย่าง ตัวตรวจจับให้ทั้งสองข้อ
- ปีหนึ่งออกได้เรื่องเดียว `must` สองเรื่องที่ถึงโอกาสสุดท้ายในปีเดียวกันจะเสียไปหนึ่งเรื่อง ให้เผื่อช่วงอายุหรือช่วงปีไว้อย่างน้อยสองปี (หมุดโลกใช้ `age: [19, 41]` เพื่อไม่ชนกับฉากปิดอายุสี่สิบ)

## เรื่องซ้ำและเหตุการณ์ที่ไม่มีตัวเลือก

- เหตุการณ์ `once: false` จะไม่ออกซ้ำภายใน `REPEAT_GAP` (5) เหตุการณ์ล่าสุด เว้นแต่ไม่มีเรื่องอื่นให้ออกเลย
- เหตุการณ์ที่ผู้เล่นคนนั้นเลือกอะไรไม่ได้สักข้อ (ทุกตัวเลือกติด `requires`) จะไม่ถูกหยิบมาแสดง เกมจึงไม่มีหน้าที่กดต่อไม่ได้
- เซฟเก่าที่ค้างอยู่ในเหตุการณ์ซึ่งไม่มีแล้วหรือเลือกไม่ได้ จะถูกพาไปเหตุการณ์ถัดไปตอนโหลด (`repairLife`)

## ตรวจชีวิตจำลอง (`npm run audit`)

เล่นชีวิตสุ่มบนเนื้อหาจริงแล้วพิมพ์รายงาน (ค่าเริ่มต้น 2,000 ชีวิต หรือ `npm run audit -- 500`) จบด้วยรหัส 1 ถ้าพบปัญหา ชุดเต็ม `npm test` รันชุดเล็ก 400 ชีวิต (`tests/slow/audit.test.ts`) ส่วนชุดเร็ว `npm run check` ไม่รัน (เมื่อไรรันอะไร ดูหัวข้อ "การทดสอบ" ของ CLAUDE.md)

- ปัญหา: ทางตัน เหตุการณ์ที่ถูกหยิบผิดเงื่อนไขหรือเลือกไม่ได้ `must` ที่หลุด เรื่องอื่นออกทั้งที่ `must` รออยู่ เรื่องซ้ำเร็วทั้งที่มีเรื่องอื่น ข้อความที่พูดถึงคนที่ตายหรือไม่มีอยู่ ค่าสเตต HP หรือเงินที่เพี้ยน ประโยคสิ้นปีที่ซ้ำในชีวิตเดียว ความตายที่ไม่มีประโยคสุดท้ายหรือไม่มีป้ายบนเส้นชีวิต และคนรอบตัวที่อายุเกิน 125 แล้วยังอยู่
- ตัวเลขสมดุล: สาเหตุการตาย เหตุการณ์ที่ไม่มีใครเห็น จำนวนเรื่องให้สุ่มในแต่ละอายุ และสองชีวิตเจอเรื่องซ้ำกันกี่เปอร์เซ็นต์ (ใช้วัดความหลากหลายก่อนและหลังเพิ่มเนื้อหา)
- หัวข้อ "ชีวิตยาว": อายุขัยต่อเผ่า ฉากตายที่ได้ออกและที่ยังไม่มีใครเห็น คู่ครองกับลูก สิ่งติดตัวที่ได้บ่อย (แยกอย่างที่เนื้อเรื่องยังไม่มีทางให้ออกจากอย่างที่มีทางได้แต่ไม่มีใครได้) ตัวเลือกที่สิ่งติดตัวปิด เหตุการณ์หลายปี และป้ายบนเส้นชีวิต
- `tests/slow/audit.test.ts` คุมเป้าสมดุลของชีวิตยาวด้วย: อายุขัยมนุษย์ (ข้อ D2) สัดส่วนที่ตายเพราะสิ้นอายุขัย นิสัยที่ไม่ควรติดเกินครึ่งของชีวิต และเพื่อนกับคู่แค้นที่ต้องมีทั้งคนที่ไปก่อนและคนที่อยู่ถึงวันสุดท้าย เนื้อหาชุดใหม่ที่ทำให้เลขหลุดช่วงจะทำให้เทสต์แดง
- เขียนเหตุการณ์ชุดใหม่แล้วให้รันทุกครั้งก่อนเปิด PR

# ชุด 1 รากของชีวิตยาว

ระบบที่เพิ่มเพื่อให้ชีวิตหนึ่งเล่นได้ตั้งแต่เกิดจนสิ้นอายุขัย ตัวอย่างการใช้จริงทุกข้อดูได้ใน `content/events/95_deaths.yaml` ถึง `99_elder.yaml` และ `tests/long-life.test.ts`

## เวลาและชีวิตยาว

- เวลาของโลกเดินเท่ากันทุกเผ่า เหตุการณ์หนึ่งเรื่องคือหนึ่งปี (ข้อ D3 ของแผนชีวิต 100 ปี แก้ L15 เดิม) เผ่าอายุยืนต่างกันแค่ร่างกายแก่ช้าหลังอายุ 40
- เรื่องเล่าจบที่ปี `STORY_END_YEAR` (410) ชีวิตที่ยังอยู่หลังปีนั้นจบแบบ "เรื่องยังไม่จบ" เอลฟ์กับคนแคระจึงยังไม่ถึงวัยชราในเนื้อหาตอนนี้
- **เหตุการณ์หลายปี** ใส่ `years: 3` เวลาจะเดินสามปีในเหตุการณ์เดียว ข้อความใช้ `{years}` แทนจำนวนปี เพราะระบบตัดให้สั้นลงเองเมื่อจะข้ามหมุดของโลก ข้ามปี 410 หรือข้ามเข้าวัยที่ต้องเช็คฤดูหนาว ถ้าเรื่องต้องใช้เวลานานจริงใส่ `min_years` ด้วย เหตุการณ์จะไม่ออกเมื่อเวลาที่เดินได้สั้นกว่านั้น
- **เหตุการณ์สำรอง** `fallback: true` ออกเฉพาะปีที่เรื่องปกติที่ออกได้มีน้อยกว่า `THIN_POOL` (3) ใช้เติมช่วงอายุที่เนื้อเรื่องยังบาง พอชุดถัดไปเขียนช่วงนั้นแน่นขึ้น เรื่องสำรองจะถอยไปเอง

## สิ้นปี: ฟื้น โรย ฤดูหนาว และข่าวของคนรอบตัว

ทุกปีหลังเหตุการณ์จบ ระบบทำสี่อย่างตามลำดับและจดลงบันทึกของปีนั้น (`entry.year`)

1. **ฟื้น** พลังชีวิตฟื้นเองตามวัย (`HP_REGEN`: ปีละ 3 ตั้งแต่ 18, 2 ตั้งแต่ 50, 1 ตั้งแต่ 65, ไม่ฟื้นเองหลัง 80) เด็กกับวัยรุ่นไม่ฟื้นเอง
2. **ร่างกายโรย** ตั้งแต่ 50 กำลังกับว่องไวมีโอกาสลด 1 ทุกปี (`DECLINE`) ไม่ต่ำกว่า 3 ปัญญา ญาณ และเสน่ห์ไม่ลดเอง
3. **เช็คฤดูหนาว** ตั้งแต่ 65 (ทีฟลิ่ง 70) ทอย d20 + อึดของร่างกายเอง (ไม่นับโบนัสจากของที่สวม) + สิ่งติดตัว + 2 ถ้ามีคู่ครองหรือลูกที่สนิทดูแล + ของกันหนาวที่สวมอยู่ (รวมไม่เกิน 2) เทียบความยากที่เริ่มจาก 8 แล้วเพิ่ม 1 ทุก 3 ปี ตั้งแต่อายุ 83 เพิ่มช้าลงเป็นทุก 8 ปี และตั้งแต่ 100 เพิ่มทุก 2 ปี พลาดแล้วพลังชีวิตสูงสุดลดถาวร 2 พลังชีวิตสูงสุดหมดคือสิ้นอายุขัย (`WINTER`) หน้าจอใช้บรรทัดทอยเดิม
4. **คนรอบตัวจากไป** คนที่อายุเกิน 60 มีโอกาสจากไปทุกปีและมากขึ้นตามวัย (`NPC_DEATH`) ข่าวมาเป็นประโยคเดียวท้ายบันทึก

เป้าของตัวเลข (เล่นสุ่ม 2,000 ชีวิต): มนุษย์ที่อยู่ถึงวัยชราสิ้นอายุขัยกลางๆ ที่ 88 เกือบครึ่งไปในช่วง 80 ถึง 90 ราวหนึ่งในสิบไปก่อน 80 และราวหนึ่งในเจ็ดอยู่ถึง 100 ทีฟลิ่งยืนกว่าราวสี่ปี คนที่เข้าร้านและสวมของยืนกว่าคนไม่แตะของราวสองปี (จากของกันหนาวและของที่เพิ่มพลังชีวิตสูงสุด) คนรอบตัวครึ่งหนึ่งอยู่ถึงราว 81

**ประโยคสิ้นปี** อยู่ใน `content/lines.yaml` ระบบหากุญแจที่ตรงที่สุดก่อน (`decline_STR` แล้ว `decline` · `news_death_<ตำแหน่งในครอบครัว>` แล้ว `news_death_<ชนิดความสัมพันธ์>` แล้ว `news_death` · `winter_fail`) ประโยคเดิมไม่ออกซ้ำในชีวิตเดียว ประโยคหมดก็เงียบ ยกเว้นข่าวการตายที่ต้องบอกเสมอ จึงควรมีหลายประโยคต่อกุญแจ

## คนในชีวิต และตัวแสดงของเหตุการณ์

คนทุกคนในผังมีปีเกิด (`born`) เนื้อหาใส่ `age:` ตอนพาเข้ามาได้ ไม่ใส่ระบบกะจากบทบาท (พ่อแม่แก่กว่า 20 ถึง 34 ปี เพื่อนกับคู่แค้นรุ่นเดียวกัน) อายุของทุกคนเดินตามปีของโลก คนนอกสายเลือดแก่แบบมนุษย์ทุกคน "รุ่นเดียวกัน" ของผู้เล่นเผ่าอายุยืนจึงนับจากวัยที่เห็นตอนรู้จักกัน (เอลฟ์อายุจริง 150 ร่างกายเท่ามนุษย์อายุ 51 เพื่อนใหม่อายุราว 51) คนที่เข้ามาหลังวัยหนุ่มสาวควรใส่ `age:` ให้ชัดเสมอ

```yaml
- id: elder.passing_friend
  cast:
    pal: { bond: [friend], min_age: 70, min_closeness: 1 }   # ต้องมีคนจริงเข้าบท ไม่มีก็ไม่ออก
  people: [{ id: "@pal", dies: true }]                        # ใช้ก่อนผลของตัวเลือก ไม่ว่าเลือกทางไหน
  mark: "{pal}จากไป"
  text: |
    {pal}ตายเมื่อสามวันก่อน ... ญาติของ{pal:เขา|นาง}จัดเลี้ยงส่งที่ร้านเหล้า
```

- `cast` บอกว่าเหตุการณ์ต้องการคนแบบไหน: `id`, `kin`, `bond`, `min_closeness`, `max_closeness`, `min_age`, `max_age` (อายุเทียบมนุษย์), `alive: false` (คนที่จากไปแล้ว ใช้กับเรื่องรำลึก), `pick` (`closest` `eldest` `youngest` `first` `random`) และ `optional: true` (ไม่มีคนเข้าบทก็ยังออกได้ แต่ใช้ชื่อบทได้เฉพาะในตัวเลือกที่มี `requires.cast`)
- ใน `effects.people` อ้างคนในบทด้วย `id: "@ชื่อบท"`
- คนที่ไม่ใช่มนุษย์และไม่ใช่ญาติสายเลือดให้ใส่ `race:` ตอนพาเข้ามา (`{ id: cohort_theril, name: เธริล, gender: m, race: elf, bond: friend, age: 19 }`) เอลฟ์กับคนแคระจะแก่ช้าและอยู่นานตามเผ่า รูปในผังก็เป็นเผ่านั้น ไม่ใส่ถือเป็นมนุษย์
- **ลูก** ใช้ `effects: { child: {} }` ระบบตั้งชื่อจากกลุ่มชื่อของบ้าน สุ่มเพศ และใส่ลงผังเป็นคนจริง (`kin: child`) เหตุการณ์ที่ให้ลูกต้องกันด้วย flag `married` เอง (ตัวตรวจชีวิตจำลองนับลูกที่เกิดโดยไม่ได้แต่งงาน ต้องเป็นศูนย์)
- **คู่ครอง** อยู่ในผังด้วย id `partner` ก่อนอายุ 100 คู่ครองไม่จากไปด้วยการทอยประจำปี ถ้าจะไปก่อนต้องเป็นฉากที่เขียนไว้ ไม่อย่างนั้นอยู่จนถึงวันที่ตัวละครจากไป
- **คนสำคัญรอฉากลา** พ่อ แม่ คนที่สนิทตั้งแต่ 3 และคนที่เนื้อเรื่องเขียนฉากตายไว้ให้ (`people: [{ id: kedra, dies: true }]` ที่ไหนสักแห่ง) ระบบไม่เอาไปเงียบๆ จนกว่าจะอายุ 88
- flag ที่ระบบตั้งให้เอง: `has_partner`, `partner_died`, `father_died`, `mother_died` ฉากที่มี `{father}` ให้กันด้วย `not_flags: [father_away, father_lost]` เหมือนเดิม ข้อความที่เอ่ยถึงคนที่ไม่อยู่แล้วระบบไม่หยิบมาแสดง

## ความตายและฉากตาย

ตัวละครไม่ตายทันที พอพลังชีวิตหมด ผลของตัวเลือกมี `die` หรือพลังชีวิตสูงสุดหมดเพราะฤดูหนาว เวลาหยุดที่ปีนั้นและเหตุการณ์ถัดไปคือ **ฉากตาย** (`stage: death`) เลือกในฉากนั้นแล้วชีวิตจึงจบ

```yaml
- id: death.age_partner
  stage: death
  mark: ฤดูหนาวสุดท้าย            # ป้ายสุดท้ายบนเส้นชีวิต ทุกทางออกของฉากตายต้องมี (ตัวตรวจบังคับ)
  when:
    dying: [age]                 # age สิ้นอายุขัย · wound แผล · fight การปะทะ (เช็คที่มี foe) · sacrifice (die: sacrifice)
    told: false                  # false = ยังไม่มีใครเล่าความตาย ฉากนี้ต้องเล่าเอง · true = ผลที่มี die เล่าไปแล้ว ฉากนี้เล่าจากข้างใน
    flags: [has_partner]
  choices:
    - id: hold_hand
      effects: { epitaph: "..." }   # ประโยคสุดท้ายของชีวิต ขึ้นใต้ชื่อในหน้าชีวประวัติ ทุกทางออกต้องมี ยกเว้นทางที่รอด
```

- ฉากตายที่ให้รอดได้ใส่ `survive: true` ในผลของตัวเลือก (ข้อเสนอของเสียงใต้ดิน ปาฏิหาริย์) คนที่กำลังสิ้นอายุขัยต้องได้ `max_hp` คืนในผลเดียวกัน
- สิ่งติดตัวที่มีผล `cheat_death` กันตายได้หนึ่งครั้งก่อนถึงฉากตาย (ไม่กันสิ้นอายุขัย)
- หน้าจอ: ฉากมืดลงไม่มีตัวละคร บันทึกปิดด้วยปีเกิดถึงปีตาย มีแผ่นปิดท้ายพร้อมปุ่มอ่านชีวประวัติ หน้าชีวประวัติแสดงภาพ ปี ประโยคสุดท้าย เส้นชีวิต สิ่งติดตัว คนที่อยู่ข้างหลัง และของที่ทิ้งไว้

## ป้ายบนเส้นชีวิต (`mark`)

เหตุการณ์ที่ควรขึ้นเส้นชีวิตในหน้าชีวประวัติใส่ `mark:` สั้นๆ ที่ระดับเหตุการณ์ ตัวเลือก (`effects.mark`) หรือผลสำเร็จกับล้มเหลว ระบบใช้ป้ายที่เจาะจงที่สุด (ผล แล้วตัวเลือก แล้วเหตุการณ์) ใช้ชื่อบทและ `{newborn}` ได้ เหตุการณ์ของโลก (id ที่มี `.world_` เช่น `adult.world_king_dies`) ขึ้นเป็นสีเน้น

## สิ่งติดตัว (`content/traits.yaml`)

ทะเบียนเดียวของพร คำสาป ลักษณะ และแผล 60 อย่าง ไอคอนอยู่ที่ `public/icons/trait_<id>.png` ตอนนี้เนื้อเรื่องให้ได้จริง 26 อย่าง (พร 2 คำสาป 1 ลักษณะ 13 แผล 10 แผลอีกห้าอย่างมาจากการปะทะในชุด 2) ที่เหลือรอชุดที่มีที่มาของมัน (เทพ เจ้าเดิม ผู้อยู่นอกฟ้า) รายงานตัวตรวจชีวิตจำลองบอกจำนวนนี้ทุกครั้ง

- ให้และถอด: `effects: { traits: [id], lose_traits: [id], trait_step: { id: 1 } }` (ขั้นของสิ่งติดตัวที่ลุกลามได้ บวกคือลุกลาม ลบคือทุเลา)
- เงื่อนไข: `when.trait`, `requires.trait`, `not_traits: [...]` (ใช้ได้ทั้ง `when` และ `requires`) และ `big_room: true` สำหรับเหตุการณ์ที่ให้พรหรือคำสาปใหญ่ (ถือได้ไม่เกิน 2)
- ผลที่ระบบคิดให้ (`effects` ในทะเบียน): `check_bonus` (เจาะจง `stats`, `foes`, `locations` ได้), `max_hp`, `regen`, `winter`, `ageless`, `cheat_death` ผลต่อการทอยขึ้นในบรรทัดทอยพร้อมชื่อสิ่งติดตัว (`roll.traits`)
- บรรทัดใน `gives` กับ `costs` ที่ระบบไม่ได้คิดให้ เหตุการณ์ต้องเคารพเองด้วย `requires` ห้ามเขียนราคาที่ไม่มีผลจริง
- กติกาของโลกที่ตัวตรวจบังคับ: พรทุกอย่างมีราคาหรือเงื่อนไข (`costs` หรือ `breaks`) คำสาปทุกอย่างมีของแถม (`gives`) ทางแก้อย่างน้อยสองทาง (`cures`) และทางอยู่กับมัน (`live_with`)

**นิสัย** ตัวเลือกติดป้าย `habit: <id>` ได้ (id ของลักษณะที่มี `habit: true`) ลักษณะนั้นติดตัวเมื่อ

1. เลือกทางของนิสัยนั้นครบ `HABIT_COUNT` (3) ครั้ง และ
2. เลือกไม่น้อยกว่าครึ่ง (`HABIT_SHARE`) ของครั้งที่ทางนั้นมีให้เลือก คนที่เลือกทางดื้อสามครั้งในร้อยปีจึงไม่ใช่คนหัวแข็ง

นับเฉพาะครั้งแรกที่เจอแต่ละเหตุการณ์ (เรื่องที่เวียนกลับมาไม่นับเพิ่ม) ตัวเลือกที่ถูกซ่อนไม่นับว่ามีให้เลือก ชีวิตหนึ่งมีลักษณะจากนิสัยได้ไม่เกิน 3 และลักษณะตรงข้ามกัน (`excludes`) ไม่ก่อตัวทั้งคู่

**สิ่งติดตัวที่ปิดตัวเลือก** มีสองทาง หน้าจอแสดงตัวเลือกนั้นเป็นล็อกพร้อมชื่อสิ่งติดตัว (ไม่ซ่อน) ทั้งสองทาง

- `blocks: [<id นิสัย>]` ในทะเบียน: คนที่ถือสิ่งนี้เลือกทางที่ติดป้ายนิสัยนั้นไม่ได้อีก (คนหัวแข็งเลือกทางขี้ขลาดไม่ได้) ต้องเขียนราคานี้ไว้ใน `costs` ด้วย
- `requires: { not_traits: [curious] }` ที่ตัวเลือก: ปิดเฉพาะตัวเลือกนั้น
- ตัวตรวจจับเหตุการณ์ที่สิ่งติดตัวอย่างเดียวปิดตัวเลือกได้ทุกข้อ

## เซฟ

การปะทะคือเหตุการณ์หนึ่งเรื่องที่ข้างในมี 2 ถึง 4 จังหวะ (แบบ "ปะทะสั้น" ที่ Phupha เลือก) ไม่มีแผนที่ ไม่มีตาเดิน ทุกจังหวะผู้เล่นอ่านว่าศัตรูกำลังจะทำอะไร แล้วเลือกวิธีรับมือหนึ่งวิธี กติกาอยู่ใน `src/engine/encounter.ts` ตัวเลขทั้งหมดอยู่ใน `ENCOUNTER` ของ `balance.ts` ตัวอย่างจริงดูได้ใน `content/events/45_youth_encounters.yaml`, `79_adult_encounters.yaml` และ `tests/encounter.test.ts`

## ศัตรู (`content/foes.yaml`)

ศัตรู 37 ชนิดตามคัมภีร์โลก ฉากอ้างด้วย `id` แล้วเขียนแค่เนื้อเรื่อง ตัวเลขของศัตรูอยู่ในไฟล์นี้ที่เดียว ภาพอยู่ที่ `public/foes/<id>.png` สองเฟรม (ยืน เข้าตี) ขนาดเฟรมอยู่ใน `public/foes/index.json` ตัวตรวจเนื้อเรื่องจับศัตรูที่ไม่มีภาพและภาพที่ไม่มีศัตรู

| ช่อง | ความหมาย |
|---|---|
| `threat` 1–5 | ความยากของการทอย (`dc`: 10 12 14 16 18) และพลังชีวิตที่เสียเมื่อพลาด (`damage`: 1 2 3 3 4 หักเกราะ) |
| `morale` 2–4 | แรงใจเป็นขีด สำเร็จหนึ่งจังหวะลดหนึ่งขีด (ทอยได้ 20 ลดสองขีด) หมดเมื่อไรชนะ |
| `weak` / `strong` | ป้ายของวิธี (`fire light water smoke noise bait name pierce blunt edge ranged`) หรือชนิดของวิธี จุดอ่อนได้ +3 เมื่อตัวละครรู้ จุดแข็งโดน −3 เสมอ |
| `speaks` | พูดรู้เรื่อง ฉากใส่วิธี `parley: true` ได้ |
| `lethal: false` | พลังชีวิตหมดแล้วล้มด้วยพลังชีวิต 1 ไม่ตาย |
| `lore` | ประโยคที่คนในโลกเล่าเรื่องจุดอ่อน ขึ้นบนหน้าจอเมื่อตัวละครรู้จุดอ่อน |
| `strike` / `hurt` | ประโยคประจำตัวตอนทำร้ายและตอนเสียแรงใจ ใช้เมื่อวิธีในฉากไม่ได้เขียน `failure` / `success` เอง ใช้ `{foe}` แทนชื่อศัตรูของฉากนั้น |
| `wounds` | แผลติดตัวที่ได้เมื่อแพ้ หรือเสียพลังชีวิตเกินครึ่งของที่มีตอนเริ่ม (ได้อันแรกที่ยังไม่มี) |

ตัวละครรู้จุดอ่อนเมื่อเป็นพราน เคยชนะศัตรูชนิดนี้ (ได้ flag `knows_<id ศัตรู>` ชื่อ flag ที่ขึ้นต้นด้วย `knows_` จึงสงวนไว้) หรืออ่านทางสำเร็จในการปะทะนั้น

```yaml
    name: โจรดักทาง              # ไม่ใส่ = ชื่อใน foes.yaml · threat, morale, deadly ทับค่าของศัตรูได้
    beats:                       # 2 ถึง 4 จังหวะ
      - text: คนถือกระบองเงื้อขึ้นจากข้างหลัง
        answer: quick            # สัญญาณ: วิธีชนิดนี้ได้ +2 ในจังหวะนี้
        moves:                   # 2 ถึง 6 วิธี id ห้ามซ้ำทั้งการปะทะ
          - { id: road_step, label: เบี่ยงตัวออก, kind: quick, success: "..." }
          - { id: road_deal, label: จ่ายสามเหรียญ, kind: talk, parley: true, requires: { min_gold: 3 } }
          - { id: road_torch, label: จุดคบไล่, kind: item, stat: DEX, tags: [fire] }
          - { id: road_dad, label: "เรียก{dad}", kind: guard, ally: dad }
          - { id: road_bolt, label: วิ่ง, kind: flee }
    win: { text: "...", effects: { gold: 4 } }
    lose: { text: "..." }        # ล้มแต่ไม่ตาย
    stalemate: { text: "..." }   # ครบทุกจังหวะแล้วแรงใจยังไม่หมด
    flee: { text: "..." }        # ต้องมีถ้ามีวิธีหนี
    parley: { text: "..." }      # ต้องมีถ้ามีวิธีเจรจา
    death: { text: "..." }       # ข้อความก่อนฉากตาย (ไม่ใส่ได้)
```

- **ชนิดของวิธี** `attack` บุก (กำลัง) · `quick` ชิงจังหวะ (ว่องไว) · `guard` ตั้งรับ (อึด) · `talk` ข่มหรือเจรจา (เสน่ห์) · `flee` หนี (ว่องไว ความยากลด `fleeEase`) · `read` อ่านทาง กับ `item` ใช้ของ ต้องระบุ `stat` เอง อ่านทางที่สำเร็จเผยจุดอ่อนและลดแรงใจหนึ่งขีดด้วย
- **คนช่วย** `ally: <บทใน cast>` ได้ +2 และวิธีนั้นขึ้นเฉพาะเมื่อมีคนเข้าบท ชื่อบทที่ไม่มีก็ได้ (optional) ใช้ได้เฉพาะในวิธีนั้น
- **ท่าของอาชีพ** ใช้ได้ครั้งเดียวต่อการปะทะ (`TECHNIQUES`): นักรบทอยใหม่เมื่อพลาดครั้งแรก นักย่องสำเร็จจังหวะแรกแล้วศัตรูเสียแรงใจเพิ่มหนึ่งขีด นักเวททอยด้วยปัญญาและนับเป็นโดนจุดอ่อน นักบวชพลาดแล้วไม่เสียพลังชีวิต (ไม่ได้เมื่อห่างจากเทพ) พรานรู้จุดอ่อนตั้งแต่แรกและได้ +2 ในถิ่นเกิด กวีได้ +3 ตอนข่มหรือเจรจา คนไม่มีอาชีพได้ +2 จากของใกล้มือ
- **ทางจบ** `win` แรงใจหมด · `parley` เจรจาสำเร็จ · `flee` หนีพ้น · `stalemate` ครบจังหวะ · `lose` พลังชีวิตหมดกับศัตรูที่ไม่เอาถึงตาย เด็กก่อนอายุ `PROTECTED_AGE` หรือคนที่มีสิ่งกันตาย · `death` พลังชีวิตหมดกับศัตรูที่เอาถึงตาย แล้วต่อด้วยฉากตายตามปกติ (`dying: [fight]`)
- บันทึกของการปะทะเก็บทุกจังหวะ (`entry.encounter`) หน้าชีวประวัติอ่านย้อนได้ เซฟที่ค้างกลางการปะทะเล่นต่อจากจังหวะเดิม

**ธรรมเนียมของเนื้อเรื่อง**

- ข้อความของทางจบและของจังหวะถัดไปต้องอ่านได้ไม่ว่าผู้เล่นใช้วิธีไหนมา และสำเร็จหรือพลาดมากี่ครั้ง
- ข้อความ `lose` ไม่บรรยายแผลถาวร เพราะแผลติดตัวระบบให้แยกและอาจไม่ได้ให้
- ลูกหลานของเจ้าเดิม (น้ำเดิน หินตื่น ไม้เฒ่า ลูกวัวใต้ทุ่ง นกหลงฝูง ลูกเสือไฟ) ชนะด้วยการทำให้สงบ ไม่ได้ฆ่า
- ศัตรูฝ่ายดาวมองไม่เห็นคนที่มีตราจอมมาร (เรื่องที่เนื้อเรื่องใบ้ไว้) ฉากของฝ่ายดาวต้องมี `when.not_traits: [curse_brand]` ตัวตรวจบังคับข้อนี้
- อย่าตั้งชื่อบทใน cast ว่า `foe` และในข้อความของฉากให้เขียนชื่อศัตรูตรงๆ (`{foe}` ใช้ได้เฉพาะในประโยคประจำตัวของ foes.yaml)
- แรงใจกับจำนวนจังหวะ (วัดจากชีวิตจำลอง ผู้เล่นที่อ่านเกม): 4 จังหวะแรงใจ 3 ชนะราว 60% · 3 จังหวะแรงใจ 2 ราว 80% · 2 จังหวะแรงใจ 2 ราว 60% ถ้าแรงใจเท่าจำนวนจังหวะในฉาก 3 จังหวะ ชนะได้ราว 40% ใช้เฉพาะฉากที่มีทางเจรจา
- ฉากประจำงาน (`flags: [job_*]`) ให้น้ำหนักสูง (ครั้งเดียว 40 เกิดซ้ำได้ 10 ถึง 20) คนในงานนั้นจะได้เจอ ความถี่รวมระบบคุมให้เอง

**ตัวตรวจ** (`npm run validate`) จับ: จังหวะที่มีวิธีเลือกได้เสมอ (ไม่มี `requires` ไม่มี `ally`) น้อยกว่าสองวิธีไม่นับการหนี · การปะทะที่เอาถึงตายแต่บางจังหวะไม่มีทางหนีที่เลือกได้เสมอ · `answer` ที่ไม่มีวิธีชนิดนั้นให้เลือก · แรงใจมากกว่าจำนวนจังหวะ · มีวิธีหนีหรือเจรจาแต่ไม่มีทางจบนั้น · `parley` กับศัตรูที่พูดไม่ได้ · id ของวิธีซ้ำ · บท optional ที่ใช้นอกวิธีของตัวเอง · ศัตรูที่มีประโยค `strike` น้อยกว่าจำนวนจังหวะของฉาก (พลาดได้ทุกจังหวะ ประโยคจะซ้ำในการปะทะเดียว)

## จังหวะของการปะทะในชีวิตหนึ่ง

- หลังการปะทะหนึ่งครั้ง ฉากปะทะทุกฉากพักไปก่อน `ENCOUNTER.gap` เหตุการณ์: สายถืออาวุธ (`ARMED_CLASSES`: นักรบ นักย่อง พราน) 2 เหตุการณ์ สายอื่น 8 เหตุการณ์
- ฉากปะทะที่เกิดซ้ำได้ออกได้ไม่เกิน `ENCOUNTER.repeatMax` (3) ครั้งในชีวิตเดียว
- ทั้งสองข้อเป็นกติกาอ่อน: ถ้าปีนั้นไม่มีเรื่องอื่นที่สดให้ออกเลย ฉากปะทะที่พักอยู่ออกได้ก่อนที่เรื่องสำรองจะต้องซ้ำ (`fightResting` ใน `engine.ts`)
- ผลจากชีวิตจำลอง: สายถืออาวุธปะทะราว 10 ครั้งต่อชีวิต (ช่วง 8 ถึง 13) สายอื่นราว 5 ครั้ง (ช่วง 4 ถึง 6) ตรงกับเป้าของแผน

## หน้าจอ

แผงการปะทะ (`src/ui/Encounter.tsx`) ใช้แบบ ก ที่อนุมัติแล้ว: ศัตรูขึ้นบนเวทีพร้อมป้ายพลังชีวิต ชื่อ ระดับภัย แรงใจ และไอคอนจุดอ่อนเมื่อรู้ ปุ่มวิธีรับมืออยู่ในแผ่นตัวเลือกเดิม พร้อมจุดบอกจังหวะและปุ่มท่าของอาชีพ ปุ่มแสดงค่าพลังกับแต้มที่จะได้จริง (ชีวิตจำลองตรวจว่าแต้มที่ทอยตรงกับที่แสดง)

**กันแตะเลย** (`reading.ts`: `tapNext`, `justRead`) ปุ่ม "อ่านต่อ" อยู่ตรงที่ตัวเลือกจะขึ้น การแตะภายใน 300 มิลลิวินาทีหลังแตะอ่านต่อจึงไม่นับเป็นการเลือก ใช้ทั้งตัวเลือกปกติและวิธีรับมือ (ปุ่มลัดบนแป้นไม่เกี่ยว)

## ชีวิตจำลองกับการปะทะ

`npm run audit` เล่นการปะทะด้วยผู้เล่นจำลองสองแบบสลับกันตามเลขชีวิต แบบอ่านเกม (เลือกวิธีที่โอกาสสูงสุด ใช้ท่าเมื่อช่วยได้ ถอยเมื่อพลาดอีกครั้งจะล้ม) กับแบบกดสุ่ม หัวข้อ "การปะทะ" ของรายงานบอก

- ผลรวมตามแบบผู้เล่น และเฉพาะการปะทะที่เอาถึงตาย (เป้า: คนอ่านเกมตายไม่เกิน 8% ต่อการปะทะที่เอาถึงตาย)
- จำนวนการปะทะต่อชีวิตของสายถืออาวุธกับสายอื่น และจำนวนครั้งที่ฉากปะทะออกทั้งที่ยังพัก
- ผลแยกตามศัตรู พร้อมพลังชีวิตเฉลี่ยตอนเริ่ม
- ฉากที่ไม่มีชีวิตไหนได้เจอ ฉากที่ไม่มีใครชนะ ฉากที่ตายเกิน 15% ฉากที่คนอ่านเกมยังตายเกิน 8% หรือชนะได้ไม่ถึง 35% ฉากเกิดซ้ำที่ชีวิตเดียวเจอกี่รอบ และศัตรูที่ยังไม่มีฉาก
- ปัญหา (ทำให้รายงานแดง): จังหวะที่ไม่มีวิธีให้เลือก แต้มที่ทอยไม่ตรงกับที่แสดง ตายในการปะทะที่ไม่เอาถึงตาย สถานะการปะทะค้างหลังจบ และฉากปะทะที่ออกทั้งที่ยังพักในขณะที่มีเรื่องอื่นให้ออก

# ชุด 2ข ของสวมใส่ ร้านค้า และของจากศัตรู

ของหนึ่งชิ้นคือ **แบบ** (`pattern` 36 แบบใน `art/gear.yaml` กำหนดช่องสวมและไอคอน) คูณ **วัสดุ** (หกอย่าง กำหนดสีและข้อได้เปรียบ) คูณ **ระดับ** (กำหนดงบค่าพลังและราคา) ชื่อกับเรื่องของทุกชิ้นเขียนด้วยมือ กติกาอยู่ใน `src/engine/gear.ts` ตัวเลขทั้งหมดอยู่ใน `GEAR`, `MATERIALS` และ `MATERIAL_EDGE` ของ `balance.ts` ตัวอย่างจริงดูได้ใน `content/items/gear_shops.yaml` และ `tests/gear.test.ts`

ตอนนี้มีของ 176 ชิ้น: ของสวมใส่ที่ซื้อขายได้ 119 ชิ้น ของใช้แล้วหมด 29 ชิ้น และของเก่าจากเนื้อเรื่องที่ซื้อขายไม่ได้ 28 ชิ้น

## ระดับ งบ และราคา

| ระดับ | ชื่อในเกม | งบ | ราคา (เหรียญ) | ได้จาก |
|---|---|---|---|---|
| `common` | ของบ้าน | 0 ถึง 1 | 1 ถึง 3 | ร้านทุกถิ่น |
| `uncommon` | ของช่าง | 1 ถึง 2 | 4 ถึง 7 | ร้านทุกถิ่น |
| `rare` | ของชั้นครู | 2 ถึง 3 | 12 ถึง 20 | ร้าน (ต้องเก็บเงิน) และศัตรูตัวใหญ่ |
| `enchanted` | ของอาบเวท | 3 ถึง 4 | 30 ถึง 50 | ร้านถิ่นละหนึ่งชิ้น ต้องแลกด้วยอย่างอื่นนอกจากเงิน |
| `hero` | ของผู้กล้า | 4 ถึง 8 | ไม่ขาย | เนื้อเรื่องเท่านั้น (ยังไม่มีชิ้นไหน) |

- **งบ** นับตาม `itemBudget`: ค่าพลัง +1 = 1 · แต้มทอย +1 = 1 · พลังชีวิตสูงสุดทุก +2 = 1 · เกราะ 1 = 1 · โล่ = 1 · ทอยใหม่ = 2 · แต้มฤดูหนาว 1 = 1 ป้ายกับวัสดุไม่กินงบ
- **เพดาน** โบนัสค่าพลังจากของทุกชิ้นรวมกันไม่เกิน +3 ต่อค่าพลังหนึ่งอย่าง (`statCap`) แต้มทอยจากของรวมไม่เกิน +2 (`checkCap`) พลังชีวิตสูงสุดจากของรวมไม่เกิน +6 (`hpCap`) ของกันหนาวรวมไม่เกิน +2 (`winterMax`)
- **ราคา** ตั้งจากรายได้จริงในชีวิตจำลอง: คนทั่วไปจ่ายร้านทั้งชีวิตราว 20 เหรียญ ซื้อของสวมใส่ราว 5 ชิ้น สามในสี่ได้ของช่างอย่างน้อยหนึ่งชิ้น ของชั้นครูมีแต่คนที่ตั้งใจเก็บเงิน
- ของอาบเวทต้องมี `caveat` (ข้อแม้หนึ่งประโยค) และถ้าวางขายต้องมี `needs` (ใครซื้อได้ พร้อม `needs_text` ที่คนขายพูดเมื่อยังไม่ขายให้) หรือ `toll` (สิ่งที่เสียเพิ่มตอนซื้อ: พลังชีวิตสูงสุด ชื่อเสียง คะแนนโลก ฝักฝ่าย flag หรือสิ่งติดตัว) ผลพิเศษอย่างที่สอง (`also`) มีได้ตั้งแต่ระดับนี้

## วัสดุ

| วัสดุ | ได้ | เสีย |
|---|---|---|
| ทองเหลือง `brass` ไม้ไอเลธ `ileth_wood` | ไม่มี | ไม่มี |
| เหล็กดำ `black_iron` | ไม่มี | เกราะตัว (`body`) หนัก หนียากขึ้น 1 และแผงของเอลฟ์ไม่ขายให้คนที่สวม |
| เงินดาว `star_silver` | +2 เมื่อบุก ชิงจังหวะ หรือตั้งรับกับฝ่ายจอมมาร | สวมข้ามปีครบ 4 ปีได้รอยดาว (`curse_star_marks`) แล้วลุกลามหนึ่งขั้นทุก 6 ปีที่ยังสวม ทีฟลิ่งและคนมีตราร้อนไม่ติด |

ข้อได้เปรียบของวัสดุไม่ทบกันหลายชิ้น ประโยคสิ้นปีของเงินดาวกับหินถ่านมารอยู่ใน `content/lines.yaml` (`gear_star_first`, `gear_star_deeper`, `gear_coal_church`)

- ไอคอนของของที่มีแบบตัดจาก `public/icons/gear_<pattern>.png` แล้วย้อมสีตามวัสดุ ของที่ไม่มีแบบ (ของใช้แล้วหมดและของที่ศัตรูทิ้ง) ใช้ภาพจากชุดภาพที่นำเข้า ลงทะเบียนใน `art/adopted.yaml` แล้วรัน `CHROMIUM_PATH=/opt/pw-browsers/chromium node art/kit/adopt.mjs` `npm run content` รวมไอคอนของทุกชิ้นไว้ที่ `public/items/<id>.png` (ไม่อยู่ใน git)
- ของนุ่ม (ผ้า หนัง) ต้องบอกในชื่อหรือเรื่องว่าวัสดุอยู่ตรงไหนของชิ้นนั้น (กระดุมทองเหลือง ซี่โครงไม้ไอเลธ) เพราะการ์ดแสดงชื่อวัสดุ
- **ของใช้แล้วหมด** ไม่มี `slot` มี `use` แทน: `heal` 1 ถึง 6 (ใช้นอกการปะทะได้เมื่อพลังชีวิตไม่เต็ม) `boost: { kinds, amount }` (วิธีชนิดนั้นได้แต้มในจังหวะที่ใช้) และ `text` หนึ่งประโยค ชนิดเดียวกันพกได้ 3 ชิ้น (`stack`) ราคา 1 ถึง 3
- เงื่อนไขใหม่ที่เหตุการณ์และตัวเลือกใช้ได้: `has_tag` (มีของติดป้ายนี้อยู่กับตัว) `wears` / `not_wears` (วัสดุที่สวม) `wears_rarity` (สวมของระดับนี้ขึ้นไป)

## ของในการปะทะ

- **ป้ายของอาวุธ** ส่งให้การบุกและการชิงจังหวะ **ป้ายของมือรอง** ส่งให้การตั้งรับและการใช้ของ ป้ายที่ตรงจุดอ่อนได้แต้มจุดอ่อนเมื่อตัวละครรู้จุดอ่อนแล้ว ป้ายจากของที่สวมไม่ทำให้ชนจุดแข็ง
- **ของใช้แล้วหมด** หยิบใช้ได้จังหวะละชิ้น ป้ายที่ตรงจุดอ่อนได้แต้มจุดอ่อนเต็มแม้ยังไม่รู้จุดอ่อน ชนจุดแข็งไม่ได้อะไร นอกนั้นได้ +1 (`thrown`) ใช้กับการหนีและการพูดไม่ได้ ยกเว้นของที่มี `boost` ของชนิดนั้น ของที่ไม่ช่วยอะไรกับวิธีที่เลือกไม่ถูกใช้ไป ยาใช้กลางการปะทะได้และฟื้นก่อนทอย
- เปลี่ยนของที่สวมกลางการปะทะไม่ได้
- **ของที่ศัตรูทิ้งไว้** `loot` ใน `foes.yaml` ทอยเมื่อชนะเท่านั้น ไล่ตารางตามลำดับ ชิ้นแรกที่ทอยติดคือชิ้นที่ได้ (ไม่เกิน `lootMax` 1 ชิ้นต่อการปะทะ) ของสวมใส่ที่มีแล้วและของใช้ที่พกเต็มถูกข้าม ศัตรู 21 จาก 37 ชนิดมีของหรือเงิน ภูตผีที่ไม่มีตัวไม่ทิ้งอะไร

```yaml
loot:
  - { item: wolf_pelt_mantle, chance: 0.25, text: "..." }   # ใช้ {foe} กับ {name} ได้
  - { gold: 2, chance: 0.5 }
```

## ร้านค้า (`content/shops.yaml`)

ถิ่นละหนึ่งร้าน (อาร์เวล เวนทราส ฮอร์ดุน ไอเลธ ดินแดนเถ้า) ร้านอยู่ที่ `location_tag` ของถิ่น ตัวละครเดินเข้าร้านเองได้ตั้งแต่อายุ 12 (`shopAge`)

- `staples` ของที่มีทุกปี (ยาและของใช้พื้นฐาน) · `stock` ของหมุนเวียน ปีหนึ่งวางแผง 5 ชิ้น (`shelf`) สุ่มใหม่ทุกปีจากปีของโลก ปีเดียวกันได้แผงเดิมเสมอ
- `requires` กับ `closed` คือร้านที่ไม่ขายให้ทุกคน (แผงของเอลฟ์ไม่ขายให้คนที่สวมเหล็กดำ)
- ซื้อไม่ได้ด้วยเหตุห้าอย่าง (`buyBlock`): ร้านไม่ขายให้ มีอยู่แล้ว พกเต็ม คนขายยังไม่ขายชิ้นนี้ให้ (`needs`) หรือเงินไม่พอ ร้านรับซื้อคืนที่ 40% ของราคา ปัดลง ไม่ต่ำกว่า 1 (`sellShare`) ของที่ไม่มีราคาขายไม่ได้
- แต่ละถิ่นมีของอาบเวทหนึ่งชิ้นที่ผูกกับคนของถิ่นนั้น: อาร์เวลขายให้คนที่นับถืออีเซล ไอเลธขายให้พราน เวนทราส ฮอร์ดุน และดินแดนเถ้าดูชื่อเสียงกับหนูท่าเรือ สภาคนแคระ และผู้คุมผนึก

## ตัวตรวจ

`npm run validate` จับ: งบไม่ตรงระดับ · ราคานอกช่วงของระดับ · ค่าพลังในชิ้นเดียวเกินเพดาน +3 · ของอาบเวทที่ไม่มีข้อแม้ หรือวางขายโดยไม่มี `needs` หรือ `toll` · `needs` ที่ไม่มี `needs_text` · `also` ในของต่ำกว่าอาบเวท · ของที่มีแบบแต่ไม่มีวัสดุ และของที่ไม่มีไอคอน · ของที่ไม่มีทางได้มา (ไม่มีเหตุการณ์ให้ ร้านไม่ขาย และศัตรูไม่ทิ้ง) · ของใช้แล้วหมดที่ไม่มีผลอะไร · ร้านที่ไม่มีของ อ้างของที่ไม่มีหรือไม่มีราคา อยู่ในถิ่นที่ไม่มีเหตุการณ์ไหนพาไป หรือไม่ขายให้ทุกคนแต่ไม่มีประโยค `closed` · `loot` ที่อ้างของที่ไม่มี · `toll` ที่แตะสิ่งอื่นนอกจากที่อนุญาต

## ชีวิตจำลองกับของ

ครึ่งหนึ่งของชีวิตใน `npm run audit` เข้าร้านทุกปี (อีกครึ่งไม่แตะของ ใช้เทียบ): สวมของที่ดีกว่าในกระเป๋า กินยาเมื่อเจ็บ ซื้อของสวมใส่ปีละไม่เกินหนึ่งชิ้นโดยเลือกชิ้นที่ได้งบเพิ่มต่อเหรียญมากที่สุด ขายชิ้นเก่า และพกยาไว้หนึ่งชิ้น ในการปะทะผู้เล่นที่อ่านเกมหยิบของเมื่อโอกาสดีขึ้นอย่างน้อย 10% หรือกินยาเมื่อพลาดอีกครั้งจะล้ม หัวข้อ "ของและร้านค้า" ของรายงานบอก

- จำนวนของที่ซื้อแยกตามระดับ เงินที่จ่าย ของใช้ที่ซื้อและใช้ ของที่ได้จากศัตรู และช่องที่สวมอยู่ตอนจบ
- ราคาของวัสดุที่เกิดจริง (รอยดาว หินถ่านมาร เหล็กเย็น)
- การปะทะที่เอาถึงตายของคนมีของเทียบกับคนไม่มี (รอบล่าสุด: ชนะ 68% กับ 61% ตาย 0.9% กับ 1.4%) อายุตอนตายของสองกลุ่ม (90 กับ 88) และเป้าข้อ D2 แยกกลุ่ม
- ของบนแผงที่ไม่มีชีวิตไหนซื้อ และของจากศัตรูที่ไม่มีชีวิตไหนได้

**ของกับอายุขัย** เช็คฤดูหนาวใช้อึดของร่างกายเอง ของที่เพิ่มอึดจึงช่วยการทอยทั่วไปแต่ไม่ยืดอายุ ของยืดอายุได้สองทางและมีเพดานทั้งคู่: ของกันหนาว (`passive.effect.kind: winter` ตอนนี้มี 9 ชิ้น รวมไม่เกิน +2) ช่วยการทอย และของที่เพิ่มพลังชีวิตสูงสุด (รวมไม่เกิน +6) ให้ร่างทนฤดูหนาวที่พลาดได้อีกหนึ่งครั้งต่อ +2 ก่อนแก้ข้อนี้คนที่สวมของอายุขัยกลางขึ้นไปถึง 98 เป้าของข้อ D2 จึงหลุด ตอนนี้มนุษย์ที่เข้าร้านสิ้นอายุขัยกลางที่ 89 ราวครึ่งหนึ่งไปในช่วง 80 ถึง 90 และ 15% อยู่ถึง 100 ส่วนคนที่ไม่แตะของเลยกลางที่ 87 และ 10% อยู่ถึง 100 (บรรทัด "มนุษย์ที่สิ้นอายุขัย (เป้าข้อ D2)" ในรายงานของ `npm run audit`)

## หน้าจอ

หน้าจอของอยู่ใน `src/ui/Gear.tsx` (Phupha เลือกแผงร้านแบบช่องไอคอนเมื่อ 11 พ.ย. 2026) ทุกส่วนอยู่ในแท็บตัวละคร เรียงเป็นตัวละครกับช่องสวมใส่ สิ่งติดตัว กระเป๋า ร้าน แล้วค่าสถานะ

- **ช่องสวมใส่** รอบตัวละคร ของที่สวมอยู่ขึ้นไอคอนในกรอบสีตามระดับ (ห้าระดับ ใช้สีที่มีอยู่ในธีม) แตะแล้วการ์ดของเปิดใต้ตัวละคร มีปุ่มถอดและขาย
- **กระเป๋า** เป็นช่องไอคอน แสดงเฉพาะของที่ไม่ได้สวมกับของใช้แล้วหมด (เลขมุมช่องคือจำนวนที่พก) แตะแล้วการ์ดเปิดใต้แถว บรรทัดบวกคือสิ่งที่ได้ บรรทัดลบคือสิ่งที่ต้องแลก ปุ่มขายต้องแตะสองครั้ง
- **ร้าน** ขึ้นเมื่อถิ่นที่อยู่มีร้านและอายุถึงเกณฑ์ คนขายทักหนึ่งประโยคต่อปี แผงเป็นช่องไอคอนมีราคาใต้ช่อง ("มีแล้ว" หรือ "เต็ม" เมื่อไม่ต้องซื้อ) การ์ดของเปิดใต้แผงพร้อมปุ่มซื้อ และเทียบกับของที่สวมอยู่ในช่องเดียวกัน กลางการปะทะและตอนใกล้ตายไม่มีร้านและเปลี่ยนของไม่ได้
- **ในการปะทะ** ของใช้แล้วหมดเป็นแถวช่องเล็กใต้หัวแผ่นวิธีรับมือ หยิบได้จังหวะละชิ้น วิธีที่ของช่วยได้ขึ้นป้ายแต้มเพิ่ม ของหมดไปเมื่อมันช่วยวิธีที่เลือก บันทึกมีบรรทัดบอกว่าใช้อะไร ของที่ศัตรูทิ้งไว้ขึ้นเป็นป้ายพร้อมไอคอนในบรรทัดสิ่งที่เปลี่ยน
- จอคอม: คอลัมน์ซ้ายมีช่องสวมใส่กับกระเป๋าเป็นช่องเล็ก แตะแล้วไปเปิดการ์ดในแท็บตัวละคร (`showItem`)

เทสต์เบราว์เซอร์สองข้อใน `e2e/layouts.spec.ts` เดินทางซื้อ สวม ถอด ใช้ขี้ผึ้ง และหยิบของในการปะทะ

# ชุด 3 องค์กร

ชีวิตหนึ่งเป็นสมาชิกขององค์กรได้ องค์กรส่งงานมาเป็นระยะ นับผลงาน เลื่อนยศ ให้ท่าในการปะทะ และมีศัตรูที่ตามล่า กติกาอยู่ใน `src/engine/orgs.ts` ตัวเลขและรายชื่อองค์กรอยู่ใน `ORG`, `ORGS` และ `TECHNIQUES` ของ `balance.ts` เรื่องของแต่ละองค์กรอยู่ในหัวข้อ "องค์กรที่ผู้เล่นเป็นสมาชิกได้" ของคัมภีร์โลก ตัวอย่างจริงดูได้ใน `tests/orgs.test.ts`

| องค์กร | id | เข้าและออก | ยศ 1 ถึง 4 | ศัตรูที่ตามล่า | ท่า (ตั้งแต่ยศ 2) |
|---|---|---|---|---|---|
| ภาคีผู้เฝ้าผนึก | `wardens` | ตามงาน: มี flag `job_wardens` หรือ `job_fort_priest` คือสมาชิก หมด flag คือพ้น | ผู้เฝ้า ผู้นับหิน ผู้ถือกุญแจ ผู้เฒ่าเจ็ดป้อม | `ash_cult` | ยืนแนว: พลาดครั้งแรกกับฝ่ายจอมมารได้ทอยใหม่ |
| โรงรับเขี้ยว | `fang_house` | ด้วย effect `org` | คนส่งเขี้ยว นักล่าป้ายทองเหลือง นักล่าป้ายเหล็กดำ เจ้าโต๊ะชั่ง | `fang_house` (นักล่าร่วมโรง) | รู้ทางเขี้ยว: สำเร็จครั้งแรกกับสิ่งที่ไม่ใช่คน ศัตรูเสียแรงใจเพิ่มหนึ่งขีด |

ยศคือระดับความไว้ใจ ไม่ใช่ตำแหน่งงาน เนื้อเรื่องประจำงานเดิม (เช่น หัวหน้ากะดึกของป้อมสาม) จึงไม่ชนกับยศ ชื่อยศเขียนลงในข้อความตรงๆ ไม่มีตัวแทนข้อความ เพราะบันทึกชีวิตแสดงข้อความด้วยสถานะปัจจุบัน

## Effects และเงื่อนไข

```yaml
effects:
  org: { id: fang_house, join: true }            # เข้า (เริ่มยศ 1) · secret: true = เข้าแบบไม่เปิดตัว ศัตรูยังไม่ตาม
  org: { id: fang_house, merit: 2 }              # ผลงานเพิ่มหรือลด (ไม่ต่ำกว่า 0)
  org: { id: wardens, promote: true }            # ขึ้นหนึ่งยศ ใช้ในฉากเลื่อนยศเท่านั้น
  org: { id: fang_house, leave: true }           # ออก ผลงานและยศหายหมด
  org: { id: fang_house, secret: false }         # สมาชิกลับถูกเปิดตัว ศัตรูขององค์กรเริ่มตาม
  hunted: { ash_cult: 1, fang_house: -1 }        # ระดับการตามล่าของฝ่ายนั้น 0 ถึง 5

when:                                            # ใช้ใน requires ของตัวเลือกได้เหมือนกัน
  org: fang_house                                # เป็นสมาชิก
  org: { id: wardens, min_rank: 2, max_rank: 3, ready: true, secret: false, min_refused: 2 }
  not_orgs: [fang_house]
  min_hunted: { ash_cult: 2 }
  max_hunted: { fang_house: 0 }
```

- `ready: true` คือผลงานถึงเกณฑ์ของยศถัดไป (`ORG.merit`: 3, 7, 12) ฉากเลื่อนยศเขียนเป็น `when.org: { id, max_rank: n, ready: true }` คู่กับ `effects.org: { id, promote: true }` และตั้ง `must: true` ได้
- องค์กรที่ผูกกับงาน (`jobs` ใน `ORGS`) เข้าออกตาม flag ของงานเอง ใช้ `join` กับ `leave` ไม่ได้ ถ้าจะให้ตัวละครเข้าภาคีกลางชีวิต ให้ตั้ง flag ของงาน และถ้าจะให้ออก ให้ `clear_flags` เซฟเก่าของคนที่ทำงานป้อมอยู่แล้วกลายเป็นสมาชิกตอนโหลด
- เข้าแบบเปิดตัวแล้ว ระดับการตามล่าของศัตรูประจำองค์กรเป็น 1 ทันที (`ORG.enemyLevel`) และไม่ลดต่ำกว่านั้นตราบที่ยังเป็นสมาชิก

```yaml
  hunt: fang_house               # ฉากของฝ่ายที่ตามล่า ออกเมื่อระดับ 1 ขึ้นไป น้ำหนักคูณด้วยระดับ
  when: { age: [28, 64] }
```

- **ผลของงาน** ทำสำเร็จ ผลงาน +1 (`ORG.done`) · ลองแล้วพลาด (ทอยไม่ผ่าน หรือแพ้ ล้ม หนีในการปะทะ) ไม่ได้ไม่เสีย · ปัด (`refuse: true`) ผลงาน −1 และองค์กรนับจำนวนครั้งที่ปัดไว้ (`min_refused`) งานที่เป็นการปะทะไม่มีทางปัด: ชนะ เจรจา หรือยันจนครบจังหวะนับว่าทำ
- **จังหวะ** (`ORG.dutyGap`) งานไม่ออกสองเหตุการณ์ติดกัน และถ้าผ่านไป 4 เหตุการณ์โดยไม่มีงานขององค์กรนั้นเลย เหตุการณ์ถัดไปคืองานขององค์กรนั้น (ถ้ามีงานที่เล่นได้) สมาชิกจึงได้งานราวทุก 2 ถึง 5 ปี งานเกิดซ้ำได้ตามกติกาเรื่องซ้ำปกติ ควรมีงานพอให้ไม่วนเร็ว
- **ฉากตามล่า** ระดับการตามล่าเพิ่มจาก `effects.hunted` และจากการเข้าองค์กร ทุกสิ้นปีแต่ละฝ่ายมีโอกาส 8% (`ORG.huntFade`) ที่จะเลิกตามหนึ่งระดับ บันทึกเป็นประโยค `hunt_cold` ใน `content/lines.yaml`
- **การปะทะของสมาชิก** สมาชิกทุกองค์กรนับเป็นสายถืออาวุธสำหรับจังหวะพักของฉากปะทะ (พัก 2 เหตุการณ์) ท่าขององค์กรทำงานเองครั้งเดียวต่อการปะทะ ไม่มีปุ่ม ยืนแนวใช้หลังท่าของนักรบและก่อนของที่ให้ทอยใหม่ รู้ทางเขี้ยวไม่ทบกับท่าของนักย่องในจังหวะเดียวกัน
- **ค่าหัว** สมาชิกโรงรับเขี้ยวที่ชนะสิ่งที่ไม่ใช่คนได้เงินตามระดับภัยของศัตรู (`ORG.bounty`: 1 1 2 2 3 เหรียญ) พร้อมประโยค `bounty` จาก `lines.yaml` (ใช้ `{foe}` ได้)

`npm run validate` จับ: `duty` ขององค์กรที่ไม่มีทางเข้า หรือไม่มี `when.org` ขององค์กรเดียวกัน · งานที่เป็น `must`, `fallback`, มี `years` หรือเป็นฉากตาย · งานแบบตัวเลือกที่ไม่มีทางปัดที่เลือกได้เสมอ หรือไม่มีทางรับที่เลือกได้เสมอ · `refuse` นอกงาน · `hunt` ของฝ่ายที่ไม่มีอะไรทำให้ตามล่า · ฉากตามล่าที่ทุกตัวเลือกที่เลือกได้เสมอจบด้วยความตาย · `join` หรือ `leave` กับองค์กรที่ผูกกับงาน · `org` ที่ไม่มีผลอะไร · `secret: true` ที่ไม่ได้มากับ `join` · เงื่อนไขที่อ่านสถานะขององค์กรที่ไม่มีทางเข้า · ช่วงยศที่กลับหัว · `min_hunted` ของฝ่ายที่ไม่มีอะไรทำให้ตามล่า

# ชุด ม เมืองและสถาบันเวทหลวง

ตัวละครอยู่ในเมืองได้ เมืองมีย่าน มีที่อยู่อาศัยที่เช่าหรือซื้อ มีชั้นของคนเมืองที่ขึ้นด้วยผลงาน และมีสภาพที่เปลี่ยนตามเหตุการณ์และติดไปถึงชีวิตถัดไป ส่วนสถาบันเวทหลวงเป็นช่วงชีวิตแบบหลักสูตร หกปี ปีละเรื่อง กติกาอยู่ใน `src/engine/cities.ts` กับ `src/engine/course.ts` ตัวเลขและรายชื่ออยู่ใน `CITY`, `CITIES`, `COURSES` ของ `balance.ts` ตัวอย่างจริงดูได้ใน `tests/cities.test.ts`

## เมืองกับถิ่น

`location_tag` ยังเป็นถิ่นเหมือนเดิม ร้านค้า ฉากหลัง และเรื่องประจำถิ่นอ่านค่านี้ เมืองอยู่ใต้ถิ่นอีกชั้นหนึ่งใน `life.city` กับ `life.district`

| เมือง | id | ถิ่น (`location_tag`) | เมืองหลักของถิ่น | ย่าน (ย่านแรกคือที่ที่คนมาใหม่ลง) | คนที่เกิดในเมือง |
|---|---|---|---|---|---|
| เวนทราส | `ventras` | `ventras` | ใช่ | `sky_docks` ย่านท่าเรือเหาะ · `refineries` ย่านโรงกลั่น · `temple_hill` ย่านวิหาร · `institute` ย่านสถาบัน | `origin_refinery` (ย่านโรงกลั่น) `origin_marked_hidden` (ย่านวิหาร) |
| คาร์ดิน | `kardin` | `kardin` | ใช่ | `junction` ย่านชุมทาง · `foundries` ย่านเตาหลอม · `ledger_row` ถนนสมุดบัญชี | ไม่มี |
| ทุนดาร์ | `tundar` | `hordun` | ใช่ | `lower_gate` ลานประตูล่าง · `forge_levels` ชั้นโรงหลอม · `clan_levels` ถนนวนของตระกูล · `council_ring` วงสภา | `origin_dwarf_clan` (ถนนวนของตระกูล) |
| เมืองตลาด | `market_town` | `arvel_village` | ไม่ | `rail_side` ย่านริมราง · `weigh_square` ลานโรงชั่ง · `mill_lane` ซอยโรงสี | ไม่มี |
| ตลาดตีนเขา | `foothill_market` | `hordun` | ไม่ | `inn_row` แถวโรงเตี๊ยม · `coal_yard` ลานถ่าน · `rail_end` ปลายราง | ไม่มี |
| หอนับดาว | `star_hall` | `ileth` | ไม่ | `root_camp` ลานโคนต้น · `letter_boughs` กิ่งจดหมาย · `count_deck` ชานนับ | ไม่มี |

- **ผล `location_tag` พาเข้าเมืองหลักของถิ่นนั้นเอง** เนื้อเรื่องเดิมที่ตั้ง `location_tag: ventras` หรือ `hordun` จึงไม่ต้องแก้ ถิ่นที่ไม่มีเมืองหลัก (`arvel_village`, `ileth`, `ashland`) คือชนบท ตั้งแล้วออกจากเมือง
- **เมืองรอง** (เมืองตลาด ตลาดตีนเขา หอนับดาว) เข้าได้ด้วย `effects.city.move` เท่านั้น ผลนี้ตั้ง `location_tag` ของเมืองให้เอง
- **คนที่เกิดในเมือง** เริ่มที่ชั้น 2 (`CITY.nativeRank`) อยู่บ้านของครอบครัวในย่านบ้านเกิด คนที่ย้ายเข้ามาเริ่มที่ชั้น 1 ไม่มีที่อยู่ ลงที่ย่านแรกของเมือง
- **ออกจากเมือง** ห้องเช่ากับบ้านของครอบครัวหลุดไป บ้านหรือร้านที่ซื้อไว้ยังเป็นของตัวเอง กลับมาเมืองเดิมก็อยู่ต่อได้ ชั้นและผลงานของแต่ละเมืองเก็บแยกกันและไม่หาย
- หมุดบนแผนที่ลงที่เมือง (`CITIES[เมือง].map` คือ id ใน `art/map/places.yaml`) แถบบนกับป้ายบนภาพฉากบอกชื่อเมืองเมื่ออยู่ในเมือง (ดูหัวข้อหน้าจอของชุดนี้)

## Effects และเงื่อนไข

```yaml
effects:
  city: { move: market_town }                    # ย้ายเข้าเมือง (ลงย่านแรก) · district: mill_lane = ลงย่านนี้
  city: { leave: true }                          # ออกไปอยู่ชนบทของถิ่นเดียวกัน
  city: { district: ledger_row }                 # ย้ายย่านในเมืองที่อยู่
  city: { home: room }                           # เช่าห้อง · none = ไม่มีที่อยู่แล้ว
  gold: -12
  city: { home: house }                          # ซื้อบ้าน (shop = ซื้อร้าน) ต้องจ่ายในผลเดียวกัน และตัวเลือกต้องมี requires.min_gold เท่าราคา
  city: { merit: 1 }                             # ผลงานต่อเมืองที่อยู่ (ไม่ต่ำกว่า 0)
  city: { promote: true }                        # ขึ้นชั้นหนึ่งขั้น ใช้ในฉากขึ้นชั้นเท่านั้น
  city: { mood: riot }                           # สภาพใหม่ของเมืองที่อยู่: calm tense riot plague
  city: { mood: plague, of: kardin }             # of = เมืองอื่นที่ไม่ได้อยู่ (ข่าวจากเมืองไกล) ใช้กับ merit ได้ด้วย

when:                                            # ใช้ใน requires ของตัวเลือกได้เหมือนกัน
  city: ventras                                  # อยู่เมืองนี้ · any = อยู่เมืองไหนก็ได้ · none = ไม่ได้อยู่ในเมือง
  city: { id: [ventras, kardin], district: [refineries, foundries], min_rank: 2, max_rank: 3 }
  city: { ready: true, max_rank: 1 }             # ผลงานถึงเกณฑ์ของชั้นถัดไป (ฉากขึ้นชั้น)
  city: { mood: [riot, plague] }                 # สภาพของเมืองที่อยู่
  city: { home: [room, none], behind: true }     # ที่อยู่: family room house shop none · behind = ค้างค่าเช่า
  city: { id: tundar, native: true, min_years: 10 }   # เกิดในเมืองนี้ · อยู่เมืองนี้มาแล้วอย่างน้อยกี่ปี
  city: { native: false, max_years: 2 }          # คนที่ย้ายเข้ามา และอยู่มาไม่เกินสองปี (ฉากของคนมาใหม่)
```

- **ชั้นของคนเมือง** สี่ขั้น: คนมาใหม่ ชาวย่าน คนมีหน้ามีตา ผู้อาวุโสของเมือง เกณฑ์ผลงาน 3, 7, 12 (`CITY.merit`) ฉากขึ้นชั้นเขียนเป็น `when.city: { max_rank: n, ready: true }` คู่กับ `effects.city: { promote: true }` และตั้ง `must: true` ได้ ชื่อชั้นเขียนลงในข้อความตรงๆ
- **ผลที่อ่านเมืองที่อยู่** (`district`, `home`, `leave`, `merit`, `promote`, `mood` ที่ไม่มี `of`) ใช้ได้เมื่อรู้ว่าตัวละครอยู่ในเมือง: เหตุการณ์มี `when.city` หรือตัวเลือกมี `requires.city` หรือผลเดียวกันมี `move`
- **เรื่องที่ใช้ได้หลายเมือง** เขียนครั้งเดียวด้วย `city: any` หรือรายชื่อเมือง ข้อความห้ามเอ่ยชื่อเมืองหรือย่าน (ไม่มีตัวแทนข้อความของชื่อเมือง)

## ที่อยู่ ค่าเช่า และร้านของตัวเอง

| ที่อยู่ | ได้มาอย่างไร | สิ้นปี |
|---|---|---|
| `family` บ้านของครอบครัว | คนที่เกิดในเมือง ได้เอง | ไม่มีค่าใช้จ่าย |
| `room` ห้องเช่า | `city.home: room` | จ่าย 1 เหรียญทุก 4 ปี (`CITY.rent`, `CITY.rentEvery`) ไม่มีจ่าย = ค้าง (ไม่เป็นหนี้) ค้างซ้ำอีกรอบ = เสียห้อง |
| `house` บ้านของตัวเอง | `city.home: house` กับ `gold` ติดลบอย่างน้อย 10 | แต้มบวกเช็คฤดูหนาว +1 (`CITY.roof` นับรวมกับของกันหนาว ไม่เกินเพดานเดิม) |
| `shop` ร้านของตัวเอง (อยู่ชั้นบน) | `city.home: shop` กับ `gold` ติดลบอย่างน้อย 14 | ได้ 1 เหรียญทุก 3 ปี (`CITY.shopIncome`, `CITY.shopEvery`) เว้นปีจลาจล และได้แต้มฤดูหนาวเหมือนบ้าน |

ค่าเช่าเบาโดยตั้งใจ: เงินที่คนหนึ่งใช้ได้ทั้งชีวิตมีราว 30 เหรียญ ค่าเช่าปีละเหรียญจะกินหมด ราคาบ้านกับร้านของแต่ละเมืองเขียนในเหตุการณ์ (ไม่ต่ำกว่า `CITY.minPrice`) ไม่มีทางเป็นหนี้จากค่าเช่าหรือการซื้อบ้าน ประโยคสิ้นปีอยู่ใน `content/lines.yaml` (`rent_paid`, `rent_behind`, `rent_evicted`, `shop_income`)

## สภาพเมือง

สภาพมีสี่อย่าง: สงบ ตึงเครียด (`tense`) จลาจล (`riot`) โรคระบาด (`plague`) เปลี่ยนด้วย `effects.city.mood` เท่านั้น ระบบไม่สุ่มให้เมืองแย่ลงเอง

- ทุกสิ้นปี เมืองที่ไม่สงบมีโอกาสคลายลงหนึ่งขั้น (`CITY.ease`: ตึงเครียด 15% จลาจล 50% โรคระบาด 40%) จลาจลคลายเป็นตึงเครียด อย่างอื่นคลายเป็นสงบ เมืองที่ตัวละครอยู่ได้ประโยค `mood_<สภาพ>_eases`
- **จลาจล** ร้านค้าของเมืองนั้นปิดทั้งเมือง (ประโยค `shop_riot`) และร้านของตัวเองไม่มีรายได้ ผลอื่นของสภาพเมือง (เจ็บ ป่วย เสียของ) มาจากเหตุการณ์ที่กันด้วย `when.city.mood` ระบบไม่หักพลังชีวิตเอง
- **ข้ามชีวิต** สภาพที่ยังไม่สงบตอนชีวิตจบเก็บลง `meta.moods` ชีวิตถัดไปเกิดมาในเมืองสภาพนั้น (แล้วคลายลงตามปีเหมือนเดิม)

## หลักสูตร (`course`)

```yaml
- id: youth.institute_gate                       # ทางเข้า: เหตุการณ์ธรรมดาที่ผลของตัวเลือกพาเข้าเรียน
  choices:
    - { id: sign, label: ..., effects: { location_tag: ventras, course: { enter: institute } } }

- id: youth.institute_first_night
  stage: youth
  course: { id: institute, year: 1 }             # เรื่องของปีหนึ่ง ทุกสำนัก · year: [3, 5] = ช่วงปี
  ...
- id: youth.institute_stars_advisor
  course: { id: institute, year: 3, track: stars }   # เฉพาะสำนักดาราศาสตร์

effects:
  course: { track: stars }                       # เลือกสำนัก ติด flag school_stars ไปตลอดชีวิต
  course: { leave: true }                        # ออกกลางคัน (เนื้อเรื่องตั้ง flag เองว่าออกเพราะอะไร)
  course: { hold: true }                         # ปีนี้ไม่นับ เรียนซ้ำปีเดิม
```

- **ระหว่างเรียน** ตัวละครมี flag `institute_student` และได้เรื่องของหลักสูตรก่อนเรื่องอื่นทุกปี ปีละเรื่อง จบเรื่องแล้วขึ้นปีถัดไปเอง เหตุการณ์ `must` ของโลกยังออกก่อนและไม่กินปีเรียน
- **จบ** พ้นปีที่หก (`COURSES.institute.years`) แล้ว flag `institute_student` หายไป ได้ `institute_graduate` เรื่องของปีสุดท้ายจึงต้องตั้งงานหรือทางไปต่อเอง
- **สำนัก** หกสำนัก: `distill` กลั่น · `machine` จักรกลเวท · `texts` ตำรา · `stars` ดาราศาสตร์ · `healing` รักษา · `war` สงคราม เรื่องที่มี `track` ออกเฉพาะคนของสำนักนั้น
- **เรื่องของหลักสูตรไม่มี `when.age` หรือ `when.year`** ออกตามปีที่เรียน คนเข้าเรียนช้าหรือเรียนซ้ำปีจึงได้เรื่องครบ เงื่อนไขอื่น (flag เผ่า ทางเข้า) ใช้ได้ แต่ทุกปีต้องมีเรื่องที่ทุกคนเล่นได้อย่างน้อยหนึ่งเรื่อง
- **ปีที่ไม่มีเรื่องของหลักสูตรเหลือให้ออก** เรื่องธรรมดาออกแทนและยังนับเป็นปีเรียน นักเรียนจึงไม่ค้างปีเดิมตลอดชีวิต รายงานชีวิตจำลองนับปีแบบนี้ ต้องเป็นศูนย์
- เพิ่มหลักสูตรอื่น (ฝึกทหาร บวช) ได้ด้วยการเพิ่มรายการใน `COURSES` ไม่ต้องแก้กติกา

## ตัวตรวจ

`npm run validate` จับ: เงื่อนไขที่อ่านเมืองที่ไม่มีทางไปถึง · ย่านที่ไม่มีในเมืองนั้น · ช่วงชั้นที่กลับหัว · `native: true` กับเมืองที่ไม่มีคนเกิด · `city` ที่ไม่มีผลอะไร หรือมีทั้ง `move` กับ `leave` · ผลที่อ่านเมืองที่อยู่โดยไม่มีอะไรบอกว่าตัวละครอยู่ในเมือง · `promote` นอกฉากที่กันด้วย `ready: true` · ซื้อบ้านหรือร้านต่ำกว่าราคาขั้นต่ำ หรือตัวเลือกไม่กันคนเงินไม่พอ · เรื่องของหลักสูตรที่ปีเกินจำนวนปี สำนักที่ไม่มี ไม่มีทางเข้าเรียน หรือเป็น `must` `fallback` `years` `duty` `hunt` ฉากตาย หรือมี `when.age` `when.year` · หลักสูตรที่บางปีไม่มีเรื่อง (ก่อนเลือกสำนักต้องมีเรื่องที่ไม่ระบุสำนัก หลังเลือกต้องครบทุกสำนัก) · `course.enter` ในเรื่องของหลักสูตร · `track` `leave` `hold` ในเรื่องที่ไม่ใช่ของนักเรียน

| หกเมือง | `67_city_<เมือง>` | 48 | เมืองละแปดเรื่อง: ปีแรก เรื่องประจำเมืองสองเรื่อง เรื่องที่ทำให้เมืองตึง จลาจล ไข้ เรื่องของคนมีหน้ามีตา และการซื้อบ้านหรือร้าน |

ข้อที่ต้องยึดเมื่อเขียนเพิ่ม:

- เรื่องของหลักสูตรต้องจริงได้ทุกปีของโลก จึงไม่เอ่ยถึงสงครามถ่านและไม่ใช้ `when.year`
- เหตุการณ์ `must` ออกก่อนเรื่องของหลักสูตร ฉาก `must` ที่นักเรียนเข้าเงื่อนไขได้ต้องกันด้วย `not_flags: [institute_student]`
- เรื่องที่ข้อความมีประตู ห้อง หรือเพื่อนบ้านของตัวละคร ต้องกันด้วย `city: { home: [...] }` ที่ระดับเหตุการณ์หรือใน `requires` ของตัวเลือกนั้น คนที่ยังไม่มีที่อยู่ในเมืองมีจริง
- ตัวละครขึ้นชั้นในเมืองได้ด้วยผลงาน ผลงานมาจากตัวเลือกที่คนในย่านจำได้ (`city: { merit: 1 }`) ชีวิตจำลองรายงานชั้นตอนจบแยกผู้เล่นที่เลือกทางของย่านทุกครั้งกับผู้เล่นที่กดสุ่ม

## ฉากใหม่

ชุดนี้เพิ่มฉาก 10 ฉาก วาดด้วยชุดวาดฉากเดิม (`art/scenes/*.yaml`) ใช้ใน `scene:` ของเหตุการณ์ได้ทุกถิ่น

| `scene` | ที่ไหน |
|---|---|
| `classroom` | ห้องเรียนของสถาบัน กระดานชนวนกับโต๊ะเขียนสองแถว |
| `library` | ห้องสมุดของสถาบัน มีชั้นลอยและซุ้มลูกกรงของชั้นที่ล็อก |
| `dormitory` | ห้องนอนห้าเตียงของหอพัก |
| `laboratory` | ห้องกลั่นของสถาบัน หม้อกลั่นเล็ก ชั้นโหล ลิ้นชักมีเลข |
| `observatory` | ห้องใต้โดมของสำนักดาราศาสตร์ |
| `council_hall` | ห้องสภาของเมือง เก้าอี้ห้าตัวกับราวกั้นคนฟัง |
| `station` | สถานีรถไฟ ชานชาลา ขบวนที่จอดอยู่ และระฆังสถานี |

ถิ่น `kardin` มีฉากของตัวเองสามฉาก: ถนนลานชุมทาง (`kardin`) บ้าน (`home_kardin`) และตลาด (`market_kardin`)

## หน้าจอ

หน้าจอของเมืองกับช่วงเรียนอยู่ใน `src/ui/City.tsx` (Phupha เลือกแบบ ข เมื่อ 12 พ.ย. 2026: ชื่อเมืองกับสภาพเมืองขึ้นบนแถบบนด้วย)

- **แถบบนและป้ายมุมภาพฉาก** ตอนอยู่ในเมืองบอกชื่อเมืองแทนชื่อถิ่น (`placeName`) เมืองไม่สงบมีจุดสีต่อท้าย: ทองคือตึงเครียด แดงคือจลาจล ม่วงคือโรคระบาด เมืองสงบไม่มีจุด
- **การ์ดเมือง** ในแท็บโลก ใต้เรื่องของถิ่น: ชื่อเมือง ป้ายสภาพเมือง ชั้นของตัวละคร ย่านทั้งหมดของเมือง (ย่านที่อยู่เป็นสีเข้ม ย่านที่มีบ้านหรือร้านมีไอคอน) บันไดสี่ขั้นของคนเมือง แถบที่ย่านจำได้เทียบกับเกณฑ์ของชั้นถัดไป และที่อยู่ ห้องเช่าบอกว่าอีกกี่ปีครบรอบค่าเช่า ค้างค่าเช่าเตือนเป็นสีแดง ร้านบอกรอบรายได้หรือบอกว่าปิดเพราะจลาจล นักเรียนที่ไม่มีบ้านอยู่ที่พักของนักเรียน บ้านหรือร้านที่อยู่เมืองอื่นขึ้นในกรอบเส้นประใต้การ์ด
- **การ์ดการเรียน** เหนือการ์ดเมืองระหว่างเรียน: ขีดละปีของหลักสูตร ปีที่เรียนอยู่เป็นสีเข้ม และสำนักที่เลือก
- **บรรทัดสิ่งที่เปลี่ยน** ย้ายเข้าเมือง ขึ้นชั้น แต้มที่ย่านจำได้ (`changes.cityMerit`) สภาพเมืองที่เปลี่ยน และที่อยู่ที่ได้หรือออก ท้ายปีมีป้ายค่าเช่าที่จ่ายหรือค้าง รายได้ของร้าน และเมืองที่สภาพคลายลง
- ย่านในการ์ดแตะไม่ได้ การย้ายย่านเกิดจากเนื้อเรื่อง บันไดสี่ขั้นใช้ชิ้นเดียวกับบันไดยศขององค์กร (`Ladder` ใน `Orgs.tsx`)

## เซฟ

เซฟเก่าได้ช่องใหม่ (`city`, `district`, `home`, `standing`, `moods`) จากค่าเริ่มต้น แล้ว `migrate` ให้เมืองตรงกับถิ่น: คนที่อยู่เวนทราสหรือฮอร์ดุนอยู่แล้วกลายเป็นคนของเมืองหลักนั้น คนที่เกิดในเมืองได้ชั้น 2 กับบ้านของครอบครัว ชั้นของคนที่ย้ายมาเริ่มนับจากวันที่โหลด `meta.moods` ของเซฟเก่าไม่มี = ทุกเมืองสงบ

# ชุด 4 ข้อห้ามของแผ่นดินและเส้นเรื่องยาว

ชุดนี้เพิ่มกติกาสามอย่าง คะแนนโลกตัวที่สี่ชื่อแผ่นดิน เครื่องหมายว่าตัวละครถือหรือฝืนข้อห้ามของเจ้าเดิมตนไหน และเส้นเรื่องยาวที่เดินเป็นตอนๆ ข้ามหลายสิบปี กติกาอยู่ใน `src/engine/land.ts` กับ `src/engine/arcs.ts` ตัวเลขและรายชื่ออยู่ใน `TABOO`, `TABOOS`, `ARC`, `ARC_IDS` ของ `balance.ts` เรื่องของโลกอยู่ในหัวข้อ "เจ้าเดิม" กับ "เส้นเรื่องยาว 12 เส้น" ของคัมภีร์โลก ตัวอย่างจริงดูได้ใน `tests/land.test.ts`

## ข้อห้าม (`taboo`)

เจ้าเดิมเจ็ดตนมีข้อห้ามตนละข้อ: `river` แม่น้ำเฒ่า · `field` วัวใต้ทุ่ง · `fire` แม่เสือไฟ · `stone` ยายหมีหิน · `forest` กวางไม่มีเขา · `wind` ฝูงนกไม่มีรัง · `night` เค้ากลางคืน ชีวิตหนึ่งจดไว้ต่อข้อว่าถือมากี่ครั้ง (`kept`) และฝืนค้างอยู่กี่ครั้ง (`broken`)

```yaml
effects:
  taboo: { river: learn }     # คนแก่สอนข้อห้ามข้อนี้แล้ว ยังไม่นับว่าถือหรือฝืน
  taboo: { river: keep }      # ถือหนึ่งครั้ง
  taboo: { river: break }     # ฝืนหนึ่งครั้ง
  taboo: { river: mend }      # ขอขมา ล้างครั้งที่ฝืนค้างอยู่ทั้งหมด
  taboo: { fire: keep, wind: break }   # หลายข้อในผลเดียวได้

when:                         # ใช้ใน requires ของตัวเลือกได้เหมือนกัน
  taboo: { id: river, taught: true }     # รู้ข้อห้ามข้อนี้แล้ว (มีคนสอน หรือเคยถือหรือฝืน)
  taboo: { id: river, keeps: true }      # ถือครบ TABOO.holds (2) ครั้ง และไม่มีครั้งที่ฝืนค้างอยู่
  taboo: { id: river, defies: true }     # ฝืนค้างอยู่ครบ TABOO.defies (2) ครั้ง
  taboo: { id: river, unbroken: false }  # มีครั้งที่ฝืนค้างอยู่ (true = ไม่มี)
```

- **ฝืน** ทำสามอย่างให้เอง: คะแนนแผ่นดินขึ้น `TABOO.land` (1) · ถ้าถือพรของเจ้าเดิมตนนั้นอยู่ (`TABOOS[id].boon`) พรหลุด · ถ้าพรนั้นมี `becomes` ในทะเบียนสิ่งติดตัว คำสาปนั้นเข้ามาแทน (พรแห่งป่าไม้กลายเป็นคนตัดไม้ พรไฟยืมกลายเป็นไฟไม่ติด) เนื้อเรื่องจึงไม่ต้องเขียน `lose_traits` หรือ `world: { land: 1 }` ซ้ำในตัวเลือกที่ฝืน
- **ขอขมา** นับเฉพาะเมื่อมีครั้งที่ฝืนค้างอยู่ คะแนนแผ่นดินลง `TABOO.mend` (1) พรที่หลุดไปแล้วไม่กลับมา คำสาปต้องล้างด้วย `lose_traits` ของเรื่องนั้นเอง
- **พร** ให้ด้วย `traits` ในตัวเลือกของเรื่องที่กันด้วย `taboo: { id, keeps: true }` ระบบไม่ให้เอง เพราะพรต้องมาในฉาก
- เซฟเก่าได้ `taboos: {}` กับคะแนนแผ่นดิน 0

## คะแนนแผ่นดิน (`world.land`)

คะแนนโลกตัวที่สี่ ต่อจาก `gods`, `demon`, `star` ช่วงเดียวกัน (−20 ถึง 20) ผู้เล่นไม่เห็น ขึ้นเมื่อมีคนฝืนข้อห้ามหรือเมื่อเนื้อเรื่องเล่าว่าเหมือง โรงงาน หรือสงครามฝืน (`world: { land: 1 }`) ลงเมื่อมีคนขอขมาหรือทำพิธี (`world: { land: -1 }`) ใช้ `world: { land: [min, max] }` ใน `when` กับ `requires` ได้เหมือนคะแนนโลกตัวอื่น ตอนจบที่ห้าของชุด 9 อ่านค่านี้

## เส้นเรื่องยาว (`arc`)

```yaml
- id: adult.arc_debt_1_surety
  arc: { id: debt, step: 1 }            # ตอนที่ 1 ของเส้น debt ต้องเป็น once: true (ค่าเริ่มต้น)
  when: { age: [27, 50] }
  choices:
    - id: sign
      effects: { flags: [signed_as_surety] }                     # จบตอนแรกแล้วเส้นเปิดเอง
    - id: walk_away
      effects: { arc: { id: debt, close: true }, flags: [refused_surety] }   # ปิดเส้น ไม่เปิดอีกในชีวิตนี้
```

| กติกา | ตัวเลข (`ARC`) | ความหมาย |
|---|---|---|
| เปิดค้างได้พร้อมกัน | `maxOpen` 3 | ตอนแรกของเส้นใหม่ไม่ออกถ้าเปิดค้างครบแล้ว |
| ระยะระหว่างตอน | `gap` 3 ปี | ตอนที่ n ออกได้เมื่อจบตอนที่ n−1 มาแล้วอย่างน้อยเท่านี้ |
| ถึงกำหนด | `due` 7 ปี | ตอนที่ค้างเกินเท่านี้เป็นเรื่องถัดไปของชีวิต ต่อจาก `must` บทเรียนของหลักสูตร และงานขององค์กร |
| เลิกนับ | `stale` 15 ปี | เส้นที่ไม่มีตอนไหนออกได้นานเท่านี้ไม่นับเป็นเส้นที่เปิดค้าง |

- รหัสเส้นทั้งสิบสอง: `relics` `debt` `horned_child` `pupil` `feud` `low_voice` `glass` `seal_secret` `climb` `faith` `house` `pillars`
- **ตอนแรก** ออกได้เมื่อชีวิตนี้ยังไม่เคยเจอเส้นนั้น ตัวเลือกที่ไม่รับเรื่องต้องปิดเส้นด้วย `arc: { id, close: true }` ไม่อย่างนั้นเส้นเปิดค้างและกินที่ของเส้นอื่น
- **ตอนถัดไป** ระบบดูแค่ว่าตอนก่อนหน้าจบแล้วและเว้นระยะครบ ตอนที่ 2 ขึ้นไปจึงไม่ควรมี `when.age` แคบ ใส่เฉพาะเงื่อนไขที่ข้อความต้องใช้ (คนในบทที่ยังอยู่ flag ของทางที่เลือกไว้) ตอนที่เข้าเงื่อนไขไม่ได้ไม่ถือว่าถึงกำหนด เส้นนั้นพักไปเอง
- **ข้อความของตอนถัดไปไม่รู้ว่าผ่านมากี่ปี** ระยะจริงอยู่ระหว่าง 3 ถึง 15 ปี เขียนว่า "หลายปี" และห้ามบอกอายุของใคร
- ตอนเดียวกันเขียนได้หลายฉบับ (แยกตามทางที่เลือกไว้ด้วย `when.flags`) ฉบับที่ออกก่อนคือตอนนั้น ฉบับอื่นไม่ออกอีก
- เส้นที่เดินถึงตอนสุดท้ายเท่าที่เนื้อหามีไม่นับเป็นเส้นที่เปิดค้าง เนื้อหาชุดหลังต่อตอนที่ 4 ขึ้นไปได้โดยไม่ต้องแก้ของเดิม
- ตอนของเส้นเรื่องเป็น `must`, `fallback`, งานขององค์กร ฉากตามล่า บทเรียน หรือฉากตายไม่ได้
- `effects.arc` ปิดเส้นจากเหตุการณ์อื่นได้ด้วย เช่น ฉากที่คนในเส้นนั้นตาย

## เงื่อนไข `any_flags`

`when` กับ `requires` รับ `any_flags: [a, b, c]` ได้ ผ่านเมื่อมี flag อย่างน้อยหนึ่งอันในรายการ (ต่างจาก `flags` ที่ต้องมีครบ) ใช้กับเรื่องที่เปิดได้จากหลายทาง ต้องมีอย่างน้อยสองอัน และทุกอันต้องมีเหตุการณ์ตั้ง

## ตัวตรวจ

`npm run validate` จับ: เงื่อนไข `taboo` ที่ไม่มีเหตุการณ์ไหนสอน ให้ถือ หรือให้ฝืนข้อนั้น · `keeps` กับ `defies` หรือ `keeps` กับ `unbroken: false` ในเงื่อนไขเดียวกัน · คำสาปที่มาจากการฝืนทั้งที่ถือพร (`becomes`) แต่ไม่มีเรื่องไหนล้างได้ · เส้นเรื่องที่ไม่มีตอนที่ 1 หรือข้ามตอน · ตอนของเส้นเรื่องที่เป็น `once: false`, `must`, `fallback`, งาน ฉากตามล่า บทเรียน หรือฉากตาย · `any_flags` ที่อ่าน flag ซึ่งไม่มีเหตุการณ์ตั้ง

## ชีวิตจำลอง

ผู้เล่นแบบ "อ่าน" ของชีวิตจำลองเลือกทางที่ถือข้อห้ามหรือขอขมาทุกครั้งที่มี รายงานมีหัวข้อ "แผ่นดิน: ข้อห้ามและเส้นเรื่องยาว": ต่อข้อห้าม กี่ชีวิตรู้ ถือครบ ฝืนซ้ำ และได้พร แยกผู้เล่นที่ตั้งใจถือกับผู้เล่นที่กดสุ่ม · การกระจายของคะแนนแผ่นดินตอนจบ · ต่อเส้นเรื่อง กี่ชีวิตได้เจอ ไปถึงตอนไหน ปิดเอง ค้างเกินกำหนด และระยะกลางระหว่างตอน ปัญหาที่รายงานนับ: เส้นเรื่องเปิดค้างเกิน `ARC.maxOpen`

## ฉากของเจ้าเดิมเจ็ดฉาก

เจ้าเดิมไม่ใช่ศัตรูที่สู้ได้ และไม่มีในทะเบียนศัตรู ตัวละครเห็นได้ในฉากพิเศษเจ็ดฉาก ซึ่งแผ่นดินในฉากคือรูปของเจ้าเดิมตนนั้นเอง ใช้ใน `scene:` ได้ทุกถิ่น เหมาะกับเรื่องที่ตัวละครไปถึงที่นอนของเจ้าเดิม ได้พร หรือขอขมา

| `scene` | เจ้าเดิม | ที่ไหน |
|---|---|---|
| `land_river` | แม่น้ำเฒ่า | ท่าน้ำเวนทราส หลังปลาบึกยาวเท่าคุ้งน้ำ หน้าผากกับหนวดสองเส้นพ้นน้ำ |
| `land_field` | วัวใต้ทุ่ง | เนินกลางทุ่งอาร์เวลที่เป็นรูปวัวนอนตะแคง รอยไถวนรอบเนิน เสาของอีเซลปักอยู่บนตัว |
| `land_fire` | แม่เสือไฟ | ปากเตาหลอมเก่าที่สุดของคาร์ดิน ไฟในเตานอนเป็นรูปเสือ ลายเป็นถ่านแดง |
| `land_stone` | ยายหมีหิน | ผาหินชนวนเหนือเหมืองเก่าของฮอร์ดุน เป็นรูปหมีแก่นอนหมอบ หิมะค้างบนหลัง |
| `land_forest` | กวางไม่มีเขา | ป่าลึกของไอเลธ กวางตัวเมียสูงเท่ายอดไม้ยืนอยู่หลังแนวไม้ สีจางเท่าหมอก |
| `land_wind` | ฝูงนกไม่มีรัง | เนินโล่งเหนือป่าไอเลธ ฝูงนกทั้งฝูงเป็นนกตัวเดียวกางปีก |
| `land_night` | เค้ากลางคืน | แดนเถ้าคืนเดือนดับ นกเค้ากางปีกคลุมฟ้าเหนือตอเสาของอัสเทล (ภาพไม่เปลี่ยนตามเวลา ใส่ `time: night`) |

ภาพของเจ้าเดิมเป็นภาพวาดของห้องวาด (`art/props/land_*.yaml`) วางลงฉากด้วยชั้น `drawing` รายละเอียดอยู่ใน `art/README.md`

## ทางไปถึงครอบครัว

เรื่องของครอบครัวในชุดนี้ต้องมีครอบครัวให้เล่า ทางไปถึงจึงกว้างขึ้น: `adult.love_meets` (น้ำหนัก 35) · `adult.life_new_love` (35 อายุ 25 ถึง 38) · `adult.life_proposal` (60 อายุ 23 ถึง 40) · `adult.life_first_child` (70 กับฉบับลูกมีเขา 14 อายุ 24 ถึง 41) · `adult.life_second_child` (30) ทุกเรื่องยังมีทางเลือกที่ไม่รับ

เด็กที่รับมาเลี้ยงใช้ flag `has_ward` (เรื่องที่รับเด็กคนใหม่กันด้วย `not_flags: [has_ward]`) เด็กเป็นคนจริงในผังครอบครัวด้วย `kin: child` รหัส `ward` (ลมบ่าย จาก `adult.hearth_child`) `ward_kin` `ward_temple` `ward_street` เรื่องที่พูดถึงเด็กในบ้านใช้ตัวแสดง `kin: [child]` ซึ่งได้ทั้งลูกและเด็กที่รับมา
